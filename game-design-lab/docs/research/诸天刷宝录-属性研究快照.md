# 《诸天刷宝录》属性研究快照

- 研究日期：2026-08-11
- 研究用途：为当前挂机游戏的属性、战斗循环与 Build 设计提供参考
- 研究定位：第一份外部样本，不代表本项目要复刻《诸天刷宝录》

## 证据口径

| 等级 | 口径 | 本项目用法 |

## 基础属性

### 五项成长值

| 属性 | 主要方向 | 设计备注 |
| --- | --- | --- |
| 勇 | 物理攻击成长 | 物理输出筛选轴之一 |
| 智 | 法术攻击成长 | 法术输出、治疗和多数护盾的核心成长轴 |
| 体 | 物理防御与生命成长 | 物理承伤轴，与精共同判断坦度 |
| 敏 | 速度成长 | 行动次数、先后手和技能循环 |
| 精 | 法术防御与生命成长 | 法术承伤轴，与体共同判断坦度 |

社区角色表常用 `勇×敏` 判断物理潜力、`智×敏` 判断法术/治疗潜力、`体+精` 判断坦度。这些是角色筛选启发式，不是最终伤害公式。

### 核心战斗面板

生命、物理攻击、法术攻击、物理防御、法术防御、速度，是五项成长值经过等级、职业、装备、技能被动及其他养成来源修正后的核心面板。

## 战斗属性

### 输出

物理增伤、法术增伤、普攻增伤、元素增伤、技能专精、武器掌握/熟练、暴击率、暴击伤害、最终增伤。

其中物理/法术、普攻、元素、专精、掌握通常被玩家资料整理为同一加法池；暴击伤害和最终增伤处于其他结算层。具体乘区与取整顺序仍需当前版本训练场复核。

### 防御与生存

物理减伤、法术减伤、元素抗性、最终减伤、生命、闪避、闪避修正、治疗加成、受疗效果、护盾上限、护盾加成。

面板防御与减伤词条要分开展示；治疗加成与受疗效果也要分成施法者端和目标端。

### 命中与易伤

命中、命中修正、闪避、闪避修正、受到物理伤害增加、受到法术伤害增加、受到元素伤害增加、受到所有伤害增加。

玩家实测资料给出过以下研究模型，但命中/闪避上下限、等级差和特殊敌人规则还没有足够可靠的当前版本证据：

```text
闪避率 = 1 - [(1 + 命中修正) / (1 + 闪避修正) × 97%]
```

### 技能循环

初始能量、每次行动能量回复、技能冷却缩减、增益持续时间、减益持续时间，以及作为核心面板的速度。

研究重点不是单项数值，而是：

```text
有效施法次数 = min（行动机会、能量供给、CD 就绪次数、AI 优先级可达性）
```

## 伤害公式与乘区收益

### 完整公式

玩家笔记整理的完整结算式（证据等级 C，未公开测量过程与版本号）：

```text
伤害 = A² / (A + D)
     × 技能描述系数
     × (1 + 物理或法术增伤 + 普攻增伤 + 元素增伤 + 技能专精增伤 + 武器熟练增伤)
     × 暴击系数
     × (1 + 增效 BUFF 系数)
     × (1 - 物法减伤)
     × (1 - 元素抗性)
     × (1 + 敌人受物法伤害增加)
     × (1 + 敌人受元素伤害增加)
     × (1 + 敌人受所有伤害增加)
     × (1 + 自己最终伤害提升 - 敌人最终减伤)

A = 面板物攻或法攻（法伤）× 攻击修正 × 职业攻击系数
D = 敌人面板防御 × 防御修正 × 职业防御系数
```

相比此前只记录 `A² / (A + D)`，这份笔记补上了三件事：

1. 攻防两端各自都是“面板 × 修正 × 职业系数”三项相乘，职业系数直接决定同一套词条在不同职业上的数量级。
2. 存在一个此前没有记录的独立乘区：增效 BUFF 系数。
3. 受物法、受元素、受所有伤害是三个相乘的乘区，不是同一个加法池；最终层则是我方终伤与敌方终减在同一括号内相减。

### 乘区形态与边际收益

除暴击系数外，每个乘区都写作 `(1 + 词条)`，即自带 100% 底数。暴击系数直接取面板值，是唯一的“裸系数”乘区。

由此可以推出一条可复现的判据（证据等级 D，研究推论）：

```text
某乘区每点相对收益 = 1 / 该乘区当前系数
```

- 自带 100% 底数的乘区起步系数为 1，每点收益随堆叠稳定衰减。
- 暴击系数的初始底数被设为 150%，玩家笔记认为与其他乘区等价应为 400%，因此爆伤每点收益被显著高估。

### 堆叠优先级结论

玩家笔记的结论（证据等级 C）：

- 攻击面板不变时，爆伤与终伤的临界比例约 `1 : 7`，即 1 点终伤 ≈ 7 点爆伤，所以基本可以无脑堆爆伤。
- 攻击面板对伤害的影响程度取决于敌人防御，只有敌人防御远大于己方攻击（100 倍以上）时，面板收益才能反超爆伤。
- 武器强化本身就提供大量面板，所以面板词条在平级与压级时不必考虑，只有越级时才需要考虑。

需要补一条推论修正（证据等级 D）：`1 : 7` 不是常数。按上面的边际收益判据，爆伤与终伤的等价点等于当前暴击系数，所以 `1 : 7` 对应暴击系数约为 7 的堆叠水平；爆伤堆得越高，终伤越早值得接手。

面板收益的方向性可以直接从核心项求出：

```text
面板弹性 = (A + 2D) / (A + D)，取值区间 (1, 2)
```

敌人防御远低于己方攻击时弹性趋近 1，远高于己方攻击时趋近上限 2。这印证了“越级才考虑面板”的方向，同时给出一个笔记没有提到的边界：即使敌人防御无限高，面板收益也只能到“翻倍面板 ≈ 四倍核心项”，不会无限增长。

## 特殊属性与跨系统标签

### 召唤属性

- 召唤强度：提高召唤物基础属性，不直接等于召唤物所有派生修正。
- 召唤数量：改变同时存在的召唤物数量，也会改变场上单位数量与承伤容错。

### 技能、元素与武器标签

- 伤害性质：物理或法术。
- 元素：公开资料涉及木、水、精神、火、土、雷、神圣、暗等元素标签，完整列表需以当前客户端为准。
- 技能类别：战技、箭弩、方术、武功、符咒、神技、魔法、斗气、召唤、忍术、机甲、医术、枪械、功法、异能等。
- 武器类型：用于连接技能与武器掌握/熟练增伤。

### 非战斗与成长效率

经验加成、职业成长、技能学习效率、工作效率和掉落率，不直接改变单次伤害，但会改变刷宝、资源和 Build 成型速度。

官方商店页还明确列出了等级、职业、位阶、技能、转职、天赋、副官、宠兽、天书、勋章等多条养成线。这些更适合作为“修正来源”建模，而不是伪装成一组基础属性。

## 机制观察

1. **ATB 行动条**：速度改变单位时间行动次数和队伍行动顺序。玩家实测研究式可写作 `行动间隔 ≈ 50 / √有效速度`，版本与测量口径需复核。
2. **自动技能优先级**：通常从技能栏左侧检查，满足能量、CD 和场景条件时释放，否则继续检查后续技能，最后使用普通攻击。
3. **攻防核心关系**：玩家实测常用 `A² / (A + D)` 解释攻防平滑收益，但不是官方公开源码。完整展开见“伤害公式与乘区收益”。
4. **伤害分层**：核心攻防、技能倍率、加法池、暴击层、增效 BUFF、减伤/抗性、三层目标易伤与最终层依次相乘，完整乘区顺序见“伤害公式与乘区收益”。
5. **状态与积层**：中毒、流血、燃烧、恢复、晕眩、减速、增伤、减伤，以及“积层→消耗”的技能链共同改变战斗节奏。
6. **召唤**：召唤物可能承担物攻、法攻、治疗或额外承伤角色，精确继承规则待核验。

## 尚未确认的边界

- 当前版本各职业精确攻击、防御和速度系数。
- 暴击伤害面板值到暴击系数的映射口径，以及“初始 150%、与其他乘区等价应为 400%”的依据。
- 增效 BUFF 系数的来源、叠加方式，以及它与加法池增伤的判定边界。
- 受物法、受元素、受所有伤害是否确实是三个相乘的独立乘区。
- “敌人防御约 100 倍于己方攻击时面板反超爆伤”所依据的词条数值口径与等级差区间。
- 公式各修正项的取整顺序、伤害浮动和溢出保护。
- 命中/闪避下限、等级差、特殊敌人修正。
- 持续伤害是否暴击以及继承哪些乘区。
- 召唤物属性继承比例与召唤数量上限。
- 治疗、复活、护盾、召唤和目标选择的完整 AI 条件。
- 最终减伤上限与技能减伤的结算先后。
