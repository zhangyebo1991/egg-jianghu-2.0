# Game Design Lab

通用游戏系统策划与研究前端工作台。它是当前项目后续开发的策划输入层，不是《诸天刷宝录》的专用资料库。

## 当前研究样本

第一批数据来自《诸天刷宝录》：

- 基础属性：勇、智、体、敏、精，以及生命、物攻、法攻、物防、法防、速度等核心面板。
- 战斗属性：输出、防御、生存、命中、易伤、治疗、护盾、能量、冷却和持续时间等词条。
- 特殊属性：召唤强度、召唤数量、伤害性质、元素、技能类别、武器类型，以及经验、掉落和经营相关成长项。
- 机制观察：ATB 行动条、自动技能优先级、能量与冷却双门槛、完整伤害乘区顺序、乘区边际收益、攻击面板弹性、状态与召唤范式。

所有条目都带有证据等级：

- `A`：官方明示
- `B`：正式版指南或高质量资料
- `C`：玩家实测 / 社区试算
- `D`：研究归纳

公式和版本敏感数值不会在没有实机验证时被当成客户端真值。

```text
src/styles.css             # 纯前端视觉与响应式布局
docs/research/             # 面向策划阅读的研究快照
docs/brainstorms/          # 项目边界与后续决策记录
```
