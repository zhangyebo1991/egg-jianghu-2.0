评审备注 · 本原型的假设与需求落点

①主界面即挂机战场：队伍常驻画卷，不再切页；所有功能收进右上角方形墨钮。
②行囊 = 换装 + 出售 + 仓储的唯一入口（已按你的要求去掉「上架」）。
③原「自动丢弃低品质」改名为「自动出售」，并注明：会在当前挂机世界自动出售（行囊页同步展示该备注）。
④势力已合并：跨世界共享任务、贡献与声望；兑换目录、招募名录合并为一个面板。
⑤悬榜支持自动接取/完成，可按任务类型（消灭/筹措/收集/挑战/寻宝）与难度勾选。
⑥已解锁的物品/武学/侠客全局可购可学；声望、贡献或世界货币不足时，提供「前往该世界挂机」直达按钮。
⑦一次性物品购买后从目录消失；非一次性物品支持多选隐藏，可在设置中恢复。
⑧未开放功能全部隐藏：城市地图/公司、秘境、土地买卖等不再出现死按钮。
⑨阵容单屏双栏：左演武场+出手次第+阵势，右点将名册常驻（独立滚动）。名册即后备，无独立后备区。交互：点阵位令牌选槽 → 右册点侠客即换防（选中留槽可连续换人）；未选槽时名册点后备一键入阵，满员则与出手末位互换并提示；点「在阵」即下阵。战场保留「布阵」快捷模式。
⑩城市仅保留古玩店经营（开关门/店员/上下架/账簿）。
⑪危险操作（删档）收进设置页深处，需二次确认；侧栏不再常驻。
⑫视觉新方向：昼卷（陈纸苔绿山水手卷 + 纯墨 + 单点绛红）/ 夜册（近墨面板）。若不认可可整体回退深色金印方向。
⑬面板双形态：宽屏默认居中册页（⇄ 一键切回右侧停靠），手机端恒全屏。大列表不堆长滚动——行囊两栏（左物品右详情）+ 展开更多；兑换目录按类折叠 + 检索；招募按位面分组折叠；顶部锚点直达分区。
