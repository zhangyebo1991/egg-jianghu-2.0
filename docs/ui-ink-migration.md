# 水墨 UI 替换记录

验收日期：2026-09-16。原型：[`UI高保真_v1.html`](UI高保真_v1.html)。应用：`egg-jianghu`。

## 已完成的替换

| 范围 | 实装行为 |
|---|---|
| 共享界面 | 宣纸山水战场、左上资源、右上十个功能入口、松烟夜册、朱砂选中态；退出旧侧栏布局 |
| 册页 | 桌面居中及右侧停靠，手机全屏；关闭按钮、遮罩、Escape、焦点约束及返回原入口 |
| 战斗 | 真实三路五列圆形令牌、气血、五颗能量珠、气机队列、波次、伤害特效和底部控制；点我方令牌查看侠客 |
| 关卡 | 同册选择十三位面、难度、小关，再确认驻守或闯荡；已解锁状态由真实进度决定 |
| 行囊 | 选择穿戴侠客、搜索、物品分类、部位与品质筛选、等级/品质排序、穿戴及卸下、详情与转职书坊市 |
| 侠客、阵容 | 资料五个子页、职业树、皮肤、装备、名册、布阵与收益加成窗口统一主题；窄屏职业树保持节点尺寸并可滚动 |
| 势力 | 悬榜、兑换、招募分别进入对应册页；武学传承保留独立子页 |
| 其他页面 | 商城、城市、设置、卷首、新建/覆写、云存档、福利奖励统一纸墨色；删档危险区放在设置内并保留确认 |

打开册页时后台战斗继续，关闭后回到同一现场。札记可展开查看真实战报和收益。横屏战场为三路、首领和操作区保留独立空间。

## 玩法和美术边界

- 原型只用于界面和交互布局。战斗事件、角色属性、城市、背包、奖励和存档继续使用游戏现有逻辑。
- 战斗速度保留实际的 `1 / 1.8 / 2.6 / 3.6` 倍；价格、掉率、位面货币和势力奖励保留真实规则，不接入原型的模拟数值。
- 城镇、秘境等原本未开放入口继续关闭；没有增加跨世界获取奖励的入口。
- 已复用原型的水墨山水底图。其余人物、敌人、装备等**尚未重新生成**，当前使用旧图去色回退。
- 素材交接见 [`UI素材清单_水墨实装_v2.md`](UI素材清单_水墨实装_v2.md) 和 [`UI素材索引_水墨实装_v2.json`](UI素材索引_水墨实装_v2.json)：1519 条逐项映射，另列 9 张通用装备回退图。
- 新图按清单放入 `egg-jianghu/src/assets/ink/`，重新构建后自动优先使用；原始素材保留。同名 WebP 优先于 PNG。
