# 蛋蛋江湖2.0 - 设计文档

**版本**：1.0  
**日期**：2026-07-30  
**平台**：网页版 + Electron桌面壳（参考 Melvor Idle 形态）  
**技术基调**：数据驱动 + Tick 循环 + 本地存档 + 自动战斗 + 可视化

## 一、核心定位与设计支柱

### 三条不可违背的设计支柱

1. **挂机是“积累”，决策是“乐趣”**  
   挂机负责刷资源、跑进度（离线也在跑），但真正好玩的部分是玩家上线后做的选择：怎么配队、点什么武学、走哪条奇遇线。挂机不能替玩家做决策，否则就没得玩了。

2. **深度来自组合，不来自数值**  
   不氪金意味着不能靠“充钱拿更高数值”续命。耐玩性必须来自 build 多样性（同样一批角色能玩出完全不同的流派）。

3. **单机友好**  
   无联网也能完整体验，进度本地可控，允许玩家“作弊式”重开、洗点、导出存档。这反而是单机不氪金游戏的最大优势。

## 二、角色收集系统（侠客 / 门客）

### 收集维度（多层叠加）

- **侠客本体**：出身门派、性格、天赋，影响成长曲线
- **武学秘籍**：独立于角色收集，可在不同角色间传授（这是组合的关键）
- **兵器/暗器/丹药**：装备层收集
- **心法/内功**：底层属性框架，决定角色能修炼哪一路武功

### 获取方式（全靠玩法，不氪金）

- 江湖奇遇（挂机随机触发招募事件）
- 门派招募 / 拜师（消耗声望、资源）
- 比武大会掉落（挑战 BOSS 侠客，打赢后招降）
- 图鉴合成（集齐碎片“考据”隐藏侠客）
- 剧情线解锁（主线/支线固定角色保底）

### 差异化设计

每个侠客给 2~3 个鲜明标签，让玩家一眼看出定位和组合价值：
- 峨眉·医者·续航
- 唐门·毒·爆发
- 丐帮·群攻·内力回充

标签既是筛选工具，也是羁绊/克制系统的挂钩点。

## 三、组合玩法（项目核心，四层叠加）

单一维度的“羁绊加成”太浅，建议做**四层正交叠加**，每层玩家都要主动经营：

### 第 1 层：武学相性（角色内部）

- 刚柔搭配：外功（刚）+ 内功（柔），纯堆一种有衰减
- 五行/属性克制：金木水火土/阴阳属性，影响队内 combo
- 走火入魔：贪多修炼冲突武学有风险，制造取舍

### 第 2 层：阵型/站位（队伍布局）

队伍不是一排站，而是阵法格子（如前中后，或 3×3 八卦阵）：
- 位置决定承伤、触发顺序、combo 链
- 特定站位组合激活“阵法”（如“天罡北斗阵”需要 7 人特定位置）

### 第 3 层：羁绊网络（角色之间）

不做简单“AB同队+10%”，做**有向、有故事的羁绊**：
- 师徒：师父在队，徒弟成长加速；师父阵亡徒弟暴走
- 情侣/结拜：一方受击另一方触发保护/复仇
- 门派：同门激活门派绝学，正邪不两立有内讧惩罚
- 宿敌：仇人同队互相削弱，但也能解锁“化敌为友”隐藏剧情

### 第 4 层：合击技 / 联手武学

两三个特定角色/武学同队解锁专属合击（美术和数值都值得为它砸资源）：
- 触发条件（能量、连携、站位）本身又是 build 的一部分
- 合击是玩家追求的“高光时刻”

**设计理由**：四层正交，玩家在任何一层都有优化空间，且互相制约（想凑合击技可能破坏阵法站位）。这就是长期可玩性的来源——永远有“再试一个配法”的动力。

## 四、挂机核心循环

`
离线/挂机产出 → 资源(银两/经验/材料/声望)
    ↓
上线做决策 → 配队/点武学/推进度/触发奇遇
    ↓
挑战关卡(闯荡江湖/爬塔/比武) → 解锁新区域+新角色+新武学
    ↓
战力提升 → 解锁更高挂机效率的区域 → 回到起点
`

**关键决策**：挂机地点可选。不同江湖区域产出不同资源（银两 / 秘籍残页 / 丹药材料），玩家根据当前需求切换挂机点——这是一个轻量但持续的决策。

## 五、其他玩法（拓展耐玩性）

- **闯荡江湖**（Roguelike 局）：一次性的随机旅程，随机事件、分叉路线、临时增益，死掉就结束，但带回永久资源
- **爬塔 / 论剑台**：无尽挑战，检验 build 上限，排行（本地历史最高）
- **比武大会 / 兵器谱排名**：阶段性 BOSS 战，追求“天下第一”的目标感
- **江湖奇遇事件**：文字选择 + 后果分支（获得角色/武功/诅咒/分支剧情）
- **门派经营**（轻）：建立自己的山庄/门派，收徒、种药、炼器，作为长线目标
- **秘籍参悟 / 武学创新**：把两本武功“合并”研究出新武学

## 六、耐玩性与长线设计

- **转生 / 新周目**：达到一定进度后重开，保留部分传承（武学感悟、传家宝），加速下一轮但换新目标/新流派
- **图鉴完成度**：侠客谱、兵器谱、武学谱、奇遇录，收集控的长期目标
- **成就 / 称号系统**：“以一敌百”“不杀通关”“纯毒流通关”等
- **周期性挑战**：每日/每周变化的江湖悬赏、限时秘境（本地时间生成）
- **难度自选 / 硬核模式**：永久死亡、禁用某系武功等自我挑战

## 七、不氪金的“健康经济系统”

- 资源产出充足但需要分配决策（银两同时用于招募、升级、炼器，逼玩家取舍）
- 没有付费墙，但用时间墙 + 决策墙制造节奏
- 可选外观/DLC 剧情章节（核心不考虑）

## 八、Melvor Idle 形态下的技术收敛

### 技术地基（已对齐）
- Tick 驱动的游戏循环（全局 tick，每 100ms）
- 纯数据驱动：侠客、武学、奇遇、掉落全部是 JSON/TS 配置表
- Tab 式界面：江湖、门派、武学、藏经阁、奇遇、图鉴、设置
- 单存档、本地优先：localStorage / IndexedDB，支持导出/导入 JSON

### 自动战斗 + 可视化落地
- 战斗面板：左右两方阵型格子（3×3 八卦阵位），每格一个侠客头像卡 + 血条 + 内力条
- 可视化表现：CSS 动画（头像抖动、飘伤害数字、技能图标弹出）、Canvas 做轻量特效
- 合击技触发时给全屏描边或连线特效
- 战斗日志侧栏：滚动文字流，服务正经武侠的叙事感
- 玩家可干预点：自动战斗保留 1~2 个手动决策（绝招能量手动放/自动放、战前换阵、危急时用丹药）

### 正经武侠调性影响
- 羁绊写成有故事的关系（师徒传承、同门情义、江湖宿仇、儿女情长），每条配一小段文案和专属效果
- 奇遇事件做成短篇江湖际遇（雨夜古寺遇高人、悬崖坠谷得残卷、酒楼卷入仇杀）
- 武学命名和体系认真设计五行/刚柔/正邪的内在逻辑

## 九、MVP 规划（先验证核心循环）

**必做**（验证“挂机→配队→变强”闭环）：
1. Tick 循环 + 离线补算 + 存档（导入/导出）
2. 一个挂机点，自动战斗打小怪，产出银两/经验
3. 8~10 个侠客（含 2~3 个门派），可招募、可升级
4. 阵型配队（先做 3 格站位，不做 3×3）+ 自动战斗可视化面板
5. 组合系统先落两层：门派羁绊 + 一个合击技
6. 3~5 本武学、简单技能树

**先不做**（YAGNI）：
- 转生、门派经营、Roguelike 局、爬塔、五行克制、图鉴完成度奖励
- 这些是核心循环验证好玩之后的“内容扩展层”
