# 职业模块对齐诸天

- 日期：2026-08-13
- 状态：已确认

## 背景与目标

把职业从现在的剑刀拳暗树，改成《诸天刷宝录》那套。这一轮先把职业数据、转职规则和界面跑通；现有武功、装备、物品清掉，下一阶段再按新职业重做。

## 核心需求

### 职业数据

- 41 个职业，名字和树与诸天 `zy.json` 一致：白丁 → 一阶 5 条 → 二至四阶各 10 → 五阶 5 个。
- 每职业包含：六维成长（物攻 / 法攻 / 速度 / 物防 / 法防 / 治疗 + 字母评级）、可用技能类型、前置职业、所需等级。
- 五阶按数据表双前置（例如主神要神殿教皇 + 法皇），职业树连线以数据为准，不按截图假连。
- 职业等级上限默认 10；经验用诸天公式（白丁 1→2 级为 114）。

### 转职

- 已修职业：直接切换，不耗书，等级保留。
- 白丁 → 一阶：白丁 Lv.5 + 对应转职书。
- 其后（含五阶）：每个前置职业 Lv.10 + 对应转职书。
- 战斗中不能转职。
- 新职业从 Lv.1、0 经验开始。

### 转职书

- 显示名：`{职业名}转职书`（如弓手转职书、护卫转职书、主神转职书）。源码里「N阶转职书」是商店分类，不是物品名。
- 弹窗条件栏文案：转职指南 / 转职指南书。
- 第一次解锁扣 1 本；已修再切不扣。
- 这一轮不出售、不开局发放；没有书就转不成（预期）。

### 角色

- 主角从白丁开。
- 招募角色各自带初始职业：等引入原版角色再做，这一轮不实现。

### 界面

- 当前职业：头像、等级、名称、六维、技能类型、经验条。
- 已修职业列表 + 底部「转职」。
- 转职弹窗为职业树；点节点看前置、书名；已修显示「可直接转职」。
- 侠客页拿掉武功栏、装备栏、圆满心得。
- 阵容只显示当前职业名和等级。
- 城市拿掉信物店和武馆。
- 背包页这一轮隐藏（书只存在存档里，界面以后再露）。

### 删除与降级

- 删除全部现有武功、心法、装备、掉落、按职业信物、圆满心得。
- 战斗只打当前职业普攻。
- 学院加职业上限、技能类型真正卡住武功：下一阶段。
- 旧存档不兼容，升版本；读到旧档当新开。

## 约束

- 借鉴诸天数据和交互，不搬原版角色与经营建筑。
- 转职书留下但不卖。
- 不自动提交 Git。

## 方案与决策

### 决策标准

- 职业树、规则、名字对齐诸天。
- 现有武功 / 装备 / 物品清掉，为下一阶段按新职业重做让路。
- 转职书用诸天物品名，这一轮不进入商店。

### 选定方向

全套换成诸天职业树与转职规则，并清空当前武功、装备、物品内容。转职书数据保留、暂不出售。主角从白丁开始；招募初始职业延后。

### 选择理由

用户明确要求「所有都改成诸天那种」，并指定删除现有武功、物品、装备。转职书是转职条件成立所必需的最小消耗品，但本阶段不提供获取途径。

### 主要备选

- 只改面板和弹窗、保留剑刀拳暗树：范围更小，但达不到「改成诸天那种」。
- 用「1阶转职书」这类按阶通用书：与诸天实际物品名不符（那是商店分类）。
- 全员从白丁开并写死：与原版「招募角色有各自初始职业」不符，且原版角色尚未引入，故本阶段只让主角从白丁开。
