# 侠客获取研究：命格、命石与培养价值

日期：2026-09-11。状态：原版静态逆向研究＋本作投放建议；未修改玩法。本文补充并修正此前只按声望初筛的分类口径。

## 1. 对章节卡池的直接结论

**一个侠客至少有三份价值：本人上阵、生产与成长用途、为主角解锁改命选项。** 还要考虑命盘能装什么石头、强势命格什么时候生效。仅看资质、声望、角色名气，都会漏掉值得长期培养的角色。

原先79人兑换／52人章节池，是原版声望的机械分组，保留作历史获取成本参考，**不再作为最终入池人数、稀有度或强弱划分依据**。本轮完成的是全量机制与条件用途分类，不把未经实战的标签伪装成强度榜。

已落盘：

- [全角色逐人表](2026-09-11-hero-fate-stone-roster.md)：193条记录逐项展示四命格真实属性、解锁位阶、用途、24槽类型，以及独有培养命格。
- [结构化全量数据](../evidence/original-world/hero-fate-stone-analysis.json)：772个命格位置、同等培养数值、同命格替代持有者及解锁位阶、资质、能力、原职业、来源哈希。
- [运行时证据](../evidence/original-world/hero-fate-stone-runtime-evidence.json)：22个事件／函数，保留表达式、SID、操作路径及改命条件原始树。

范围为193条原版角色：189个非占位定义，扣除主角后188名伙伴；4个未知占位不入池。本作30名自创酒馆角色不在原版命格表内，仍见[此前分类](2026-09-11-hero-acquisition-classification.md)，不能替他们捏造原版命盘。

## 2. 命石、命格、天命分别做什么

| 层次 | 来源及作用 | 对角色价值的影响 |
| --- | --- | --- |
| 命石属性 | 装在命盘中的石头，各自增加对应属性，按石头等级计算 | 可卸下换装；不能把可搬走的命石属性全算成侠客专属优势 |
| 四个命格 | js第28～31列引用mg；各有一个属性、系数和六槽类型 | 角色位阶决定是否生效，关联命石天命值决定命格等阶 |
| 总天命 | 全32槽命石天命值合计，换算总天命等阶，再进入角色成长天资属性 | 资质仍然重要，但不是四命格效果的替代指标 |
| 主角改命收藏 | 拥有并培养角色后，开放相应命格给主角替换 | 不上阵的角色也可能成为长期获取目标 |

mg的品质档、命格等阶、命石等级、总天命等阶、角色转生位阶是不同字段。全193条js的初始位阶均为1，不表示全部同稀有度，也不表示四命格开局全生效。

属性汇总以“角色编号”为输入。本轮没有证据支持把任意命格直接解释成全队光环：治疗、护盾或增益可以通过角色施放的技能帮助队友，具体覆盖对象仍取决于技能；工作、掉落属性也必须核对对应结算入口，不能直接写成全队、账号全局或蛋蛋产出加成。

## 3. 解锁节奏：招到与养成是两次体验

`命格总属性function`明确要求角色位阶≥命格位置。第一命格招到即可生效；其余三个依次要求二、三、四阶。即使关联石槽提前开放，也不绕过这个门槛。

| 内容 | 原版条件 | 设计含义 |
| --- | --- | --- |
| 第一命格 | 位阶1 | 应作为招到时的直接卖点 |
| 第二命格 | 100级、前置六槽解锁、转生材料，完成一转 | 不能把二阶效果写成招到就有 |
| 第三命格 | 200级、前置六槽解锁、转生材料，再转生 | 更适合作为中期培养目标 |
| 第四命格 | 300级、前置六槽解锁、转生材料，再转生 | 高系数终局卖点可能要很晚才能兑现 |

mp表与`天赋格解锁function`显示槽位按顺序解锁，并检查等级、位阶与材料：

- 1～6槽的表内等级／物品门槛为0；初始存档初始化仍需与实际开局对应。
- 7～12槽：15／30／45／60／75／90级，每槽10个67号物品。
- 13～18槽：115～190级，每15级一个，每槽20个68号物品。
- 19～24槽：215～290级，每15级一个，每槽30个69号物品。
- 25～32槽：312～396级，每12级一个，每槽40个70号物品。

转生检查当前阶段六个前置槽是否全部解锁，并把位阶和等级各加1。这里是原版等级条件，**不能换算成现实几天**；本作经验曲线、材料供给和离线推进并未在本轮测定。继承哪些转生机制也尚未确认；本轮不引入重复抽卡升星。

## 4. 命盘本身是角色差异

mg第6～11列是六个基础槽的类型：1攻击、2防御、3特殊、4通用。石头的ms第1列必须匹配槽类型，通用槽允许不同类型命石；25～32为公共通用槽。嵌入点击逻辑明确检查这些条件，不是仅有颜色区别。

四个命格关联槽位分别是：

| 命格位置 | 六个基础槽 | 额外通用槽 |
| --- | --- | --- |
| 1 | 1～6 | 26、27 |
| 2 | 7～12 | 25、29 |
| 3 | 13～18 | 30、31 |
| 4 | 19～24 | 28、32 |

前24槽：甄宓为6攻／11防／5特／2通，华佗6攻／5防／5特／8通，昊天12攻／0防／4特／8通。昊天没有固定防御槽不等于不能装防御石，仍可使用通用槽；通用槽越多说明搭配余地更大，不等于在任何配置下伤害越高。

石头还同时提供自身属性与命格／天命进度。相同石头数量，不同类型分布可能使一名侠客更容易凑输出，另一名更适合生存；因此统一装备比较时，还要保证命石方案合法。

## 5. 同进度下比较数值

本次772个命格位置引用的属性全部落在sx“乘法＋百分比”分支。原版显示函数直接在数值后加百分号，不再乘100。

设石头等级为L、命格等阶为T、mg系数为C、sx默认尺度为B：

```text
单石天命值 = clamp(ceil(L / 50), 1, 9)²
命格等阶T = max(1, floor(sqrt(对应8槽的已装石天命值之和)))
总天命等阶 = max(1, floor(sqrt(全32槽天命值之和 / 4)) + 1)
命格百分比属性值 = round(0.25 × T × C × B) / 100
```

无石时命格等阶最低仍是1，已激活命格并非零效果。石头1～50级天命值为1，51～100级为4，101～150级为9，最高档天命值81。命石合成函数成功时等级增加50，跨档能提升关联命格；命石自身属性仍按具体等级算。

| 受控示例 | 对应命格等阶 | “济世”治疗加成（C180、B20） |
| --- | ---: | ---: |
| 已激活、未装石 | 1 | +9% |
| 6颗1级石 | 2 | +18% |
| 6颗201级石 | 12 | +108% |
| 8颗401级石 | 25 | +225% |

这些是公式代入，不是实机治疗量测试。四阶角色不等于命格等阶4；高百分比也不等于实战同比提升，因为还有其他同类属性、技能条件和最终结算。

按该函数，单命格8石的天命值上限为648，对应T25；全32石上限2592，对应总天命26。这是天命值封顶推导，不代表所有命石自身属性在401级停止成长。

sx中暴击、减伤、冷却等存在上限字段，但本轮未把各属性所有消费端、取整和封顶顺序逐一复核。因此不据此给出精确DPS、满减伤或冷却收益承诺。

## 6. 主角改命：获取角色还有收藏价值

`刷新命格解锁数据function`对已拥有角色做两种标记：四个命格标为已见，达到对应位阶才标为已解锁。看到第四命格，不等于主角已可使用。

`改命命格点击`中的条件组为OR：已解锁标记为1，**或**mg第14列为1的默认开放命格，即可继续检查成本和空间。替换写入的是`save[1, 34+位置, 1]`，即主角；没有发现该入口允许任意伙伴自由换四命格。

改命消耗mg第13列星魂，并退还旧命格对应成本；换命会卸下对应六个基础槽的命石，并要求背包空间。主角自身仍需达到相应转生位阶才能选择该位置。

这意味着：

- 独有、非默认开放的强势命格，可以支撑“拿到角色→养到目标位阶→丰富主角构筑”的长线目标。
- 相同命格若多人持有，应比较最早章节、最早解锁位阶、培养成本；不能把其中一人宣传成唯一来源。
- mg默认开放的命格不应被当作抽到该侠客才解锁的稀缺奖励。
- 本研究只证明角色收藏能开放改命选项，不承诺主角可任意跨位置组合、装重复命格或无限叠加；这些选择器限制在正式设计时还需单独核验。

## 8. 建议的投放方法（尚未确认）

先按用途挑每章阵容，再决定兑换还是池，不固定每章必须6换4抽：

1. **确定兑换提供可用底座**：每章保留能完成该章内容的输出、生存或治疗选择；后勤与基础刷宝路线有确定来源。优秀角色也可以兑换，形成玩家能规划的培养目标。
2. **章节池提供有条件的构筑提升**：候选需要明确描述“一阶能做什么、培养后哪一阶改变配队、哪些技能能吃到加成”。只有泛用数值更高、缺乏本作实际效果支撑的角色暂不定价。
3. **副本／里程碑提供长线目标**：原版精魄角色、赵云等保留独立获取讨论，不把所有值得拿的角色统一塞入蛋蛋池。
4. **独有命格形成收藏支线**：如果本作决定继承主角改命，获取和培养角色本身即可增加可选构筑，不需要角色重复升星。具体命格继承范围待定。

为了同时耐玩和有获得感，卡池角色的一阶应有可用理由，后续培养再放大或拓展用途。如果卖点只有很久以后才解锁的第四命格，招到当下容易缺乏反馈。反过来，把所有掉落／工作效率优点只放进高级池，会使玩家被迫先攒产出角色，削弱自由配队；建议这些路线至少保留一个确定获取目标。

本轮不确定蛋蛋抽价、概率、保底或最终人数。那些参数必须在本作选定继承的命格效果、获取节奏与替代阵容之后评估；收益卡不影响抽池、普通素材与打造维持原路线等已确认边界继续有效。

## 9. 证据边界与下一轮评估标准

来源为本机`../诸天刷宝录/_analysis`基线1.2.2.0，查表与解码事件来自同一快照；不是线上最新官方版本声明，也没有逐人实机战斗验收。

当前本机package.nw的js与该基线有三处命格ID差异：因陀罗二命格280→279、芙蕾雅三命格243→239、共工四命格238→239。JSON保留差异；新ID的文字解释仍使用基线mg，不冒充当前归档完整机制。三人暂不用于最终稀有度比较。

当前本作原版四命格属性链尚未完整接入，因此研究得到的原版用途不等于现版本已经生效。后续确定最终池名单时，对候选与确定兑换替代同时检查：

- 相同等级、位阶、资源预算及合法命石配置下，分别看刚获得、二／三阶、四阶三个时段。
- 清怪速度、Boss输出、承伤／续航、施法循环分别比较，避免一个总评分遮掉长处。
- 生产类按对应工作实际投入与收益比较；掉落类核对谁参与结算、统计口径和边际收益。
- 除同命格来源，还要比较同属性不同命格、装备／命石替代；JSON的同命格持有者是第一层替代检查，不是完整不可替代证明。
- 主角改命是否继承、技能与职业如何适配，属于下一轮设计取舍；不因本文落盘就自动实施。

验收：193个ID唯一且连续；772个位置全部解析到命格及属性；188个伙伴可列为投放研究对象；4个占位排除；公式示例交叉核算；文档与JSON口径一致。无需为纯研究文件运行业务构建。
