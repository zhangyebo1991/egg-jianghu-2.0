# 各位面怪物替换为诸天原版

- 日期：2026-08-13
- 状态：已确认

## 背景与目标

当前怪物是程序生成：名字来自金庸风名池（仅覆盖 world_01–10，与 13 位面主题错位），立绘按档位从 7 张通用图哈希选取，全员只有普攻。目标是把 13 位面 × 10 关的怪物全部替换为《诸天刷宝录》原版怪物（普通怪、精英怪、首领），形象全量采用原版立绘。

## 核心需求

### 怪物内容表

- 新建 `src/content/enemies.ts`，由一次性 node 脚本从原版 `_analysis/sq.json`（地点 → 5 小怪 + 1 首领）与 `dr.json`（463 行怪物图鉴）导出。
- 13 位面 × 10 关，每关固定 5 种小怪 + 1 名首领，名字用原版（黄巾战士、随军参谋、张角、貂蝉……）。
- 只导位面关卡怪（约 130 小怪 + 130 首领）；原版副本怪、灵兽不导。
- 替换 `enemy-names.ts` 名池机制，world_11–13 名字缺口随之补齐。

### 波次构成

- 保留现有 10 波骨架：普通波 2–4 只、3/6/9 波末位精英、第 10 波首领波。
- 波内怪物从「本关 5 小怪」按 seed 抽取。
- 精英按原版规则 = 同名小怪数值升级（倍率对齐原版 ×1.5），不是独立图鉴怪。
- 第 10 波 = 本关首领 + 2 只本关小怪。

### 数值

- 保留现有 scale 平衡公式（位面/难度/关/波递增）。
- 引入原版 `drsx.json` 六维成长系数做同关怪物差异化（攻高血薄、血厚防高等）。
- boss 倍率维持现状；精英倍率从 1.65 对齐为原版 1.5。

### 形象（全量切图）

- 切图管线：解压 `package.nw`（zip）→ 解析 `data.json`「角色形象」对象的动画帧矩形（sheet 路径 + x/y/w/h，已验证可解析）→ 从 `images/角色形象-sheet*.webp` 裁切 → 输出约 260 张立绘到 `egg-jianghu/src/assets/enemies/`。
- 小怪形象引用 `dr` 列 2 的数字动画名，首领引用同名动画（如「张角」）；数字动画的全局唯一性在写切图脚本时验证。
- `portrait-assets.ts` 的 `enemyPortraitAsset` 改为按怪物 id 查表；现有 7 张通用档位图仅作缺图兜底。
- 切图脚本可临时引入图像处理库（如 sharp），仅工具链使用，不进运行时依赖。

### enemy id 与存档

- enemy id 从波内槽位制（`normal_N`/`elite_N`/`boss`）改为怪物身份制：`world_XX_stage_YY_mob_1..5` 与 `world_XX_stage_YY_boss`。
- 保留 `world_XX_` 前缀，悬榜任务按位面前缀过滤的逻辑不变。
- 旧格式按波内槽位命名会导致悬榜目标名不稳定（同槽位跨波可能是不同怪），必须改。
- 存档 version 13 → 14，旧档不迁移当新开（沿用清档惯例）。

### 悬榜与遭遇记录

- `encounteredEnemyIds` 与任务 `targetId` 改用新 id，语义不变（见过才能上悬榜、按 id 精确计数）。
- 悬榜 UI 显示原版怪名（`enemyDisplayName` 改查怪物内容表）。

## 约束

- 战斗引擎骨架、平衡公式、波次节奏不动。
- 中文文案；不自动提交 Git。
- 英雄与敌人重名校验（`validate.ts`）需对新名单继续生效。

## 方案与决策

### 决策标准

- 怪物名单、精英规则、首领归属忠实原版 `sq.json`/`dr.json`。
- 形象全量还原（用户选定），数值平衡沿用现有体系不重调。
- 本版最小范围：不做技能、不做位掩码范围、不做图鉴页。

### 选定方向

内容表驱动出怪：sq/dr 导出每关 5 小怪 + 1 首领，波次骨架保留、波内查表抽怪；全量切原版立绘；enemy id 改身份制并升存档 v14 清档。

### 选择理由

原版精英本就是同名小怪的运行时升级，与现有 rank 体系天然吻合；保留 scale 公式避免重新平衡英雄数值；身份制 id 让悬榜目标名稳定且保留位面前缀过滤契约。

### 主要备选

- 怪物立绘沿用通用档位图或只切首领：还原度不足，用户选定全量切图。
- boss 技能简化复刻或完整复刻（fw.json 位掩码范围 + jn.json 公式）：工程量大，用户选定本版不做，boss 暂用普攻。
- 数值改用原版 drsx × 难度公式：与自有英雄数值体系平衡风险大，未选。
