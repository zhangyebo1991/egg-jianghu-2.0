# 养成闭环：装备与转职书

- 日期：2026-08-14
- 状态：已确认

## 背景与目标

职业、位面、阵容、怪物和战斗技能已对齐诸天；玩家仍只有职业普攻，转职书买不到，装备掉落和背包也停了。本阶段把 **刷装穿戴** 和 **转职书获取** 接上，挂机重新能变强、职业树能走。玩家技能学习留到城镇 / 势力。

## 核心需求

**装备**

- 击杀立刻掉装；满 300 格跳过、战斗继续。小怪 / 精英 / 首领只提高件数和高品质权重。
- 从 `wp.json` 按位面风格抽具名装备（部位 1–8：武器、副手、头、身、护腕、足、项链、戒指）。只进普通 / 特殊；套装效果、至宝、勋章不做。
- 现场掷物品等级（位面 + 难度 + 关）和凡品→绝品；词条进现有面板。武器类型只展示，不覆盖普攻、不结算熟练。
- 人物等级 < 物品等级不能穿。侧栏恢复背包；侠客页恢复 8 槽和三套方案；锁定 / 丢弃 / 整理 / 批量丢弃保留。
- 坊市不卖成品装。金庸旧名停用。

**转职书**

- 背包坊市按阶卖 `{职业名}转职书`（一至五阶，不含白丁），花当前位面铜钱，价格随阶涨。可先囤，转职仍要前置等级。
- 战斗不掉转职书（含小怪 / 精英 / 首领）。第一次解锁扣 1 本，已修再切不扣。

**不做**

- 玩家技能学 / 升 / 四槽 / 秘籍 / SP。
- 城市、势力、商会地图；装备强化 / 图纸 / 淬炼。
- 诸天角色、神界、星魂、诸天宝录。

## 约束

- 出手与伤害骨架不动；玩家进战仍是职业普攻。
- 城镇 / 势力仍隐藏，不为此临时做技能学习入口。
- 中文文案；存档升版，旧档当新开；不自动提交 Git。

## 方案与决策

### 决策标准

- 养成闭环先补装备和转职；技能学习必须等原版入口（武馆 / 势力 / 秘籍）。
- 转职书获取不走战斗掉落，避免和原版「商会 / 势力 / 城镇购买」混成第二套随机源。

### 选定方向

掉落具名装 + 背包穿戴；转职书只在背包坊市用铜钱购买。

### 选择理由

装备本就从战斗掉；转职 UI 已有、只缺书。技能学习绑在未做的城镇 / 势力上，本阶段不做临时学技能。转职书原版也是买的，本阶段用坊市做最小入口，不从击杀掉。

### 主要备选

- 技能 + 转职 + 装备一次做完（技能学习改掉落 / 坊市）：与原版入口不符，已排除。
- 精英 / 首领低概率掉转职书：用户指定不掉，仅坊市出售。
