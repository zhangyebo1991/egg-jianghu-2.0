# 侠客页面原型重设计（职业/转职/品级/根骨新体系）

- 日期：2026-08-14
- 状态：已确认

## 背景与目标

旧原型 `docs/侠客页面重设计.html` 停留在旧体系（职业进阶/圆满心得、四槽武功、主修心法、七部位装备），游戏实现已换成诸天体系（见 `docs/brainstorms/2026-08-13-career-zhutian.md`），原型过期。

游戏现状（`egg-jianghu/src/ui/heroes-page.ts`）：三栏（点将谱/列传/行囊）；列传含根骨资质（五维雷达+属性分页+核心六维+能力等级）、随身装备（八部位三套方案）、当前职业（成长评级+已修+转职）、职业树弹窗（41 职业，初级→五阶，转职书）。品级（稀有度）= `HeroGrade` 丙/乙/甲/地/天，主角为「主」；根骨资质 = 五维（臂力/悟性/体魄/身法/定力，白板全 10 总和 50）。

目标：重设计 `docs/侠客页面重设计.html` 原型以适应新内容，作为下一步游戏 UI 实现的设计稿（沿用「原型先行 → 实现跟进」工作流）。

## 核心需求

### 功能

- **页面骨架（两栏）**：左 点将谱，右 列传；列传 = 常驻侠客头部 + 页签切换（根骨资质 / 随身装备 / 职业转职）。
- **点将谱**：搜索、品级筛选（丙乙甲地天）、脉系筛选（剑刀拳暗医内）；条目按品级着色，显示头像、名、当前职业与等级、在队/主角标记。
- **列传常驻头部**：品级印章（整卡分级）、头像、姓名、标签（X品侠客/天命主角、脉系、来源）、等级 + 当前职业名。
- **签一·根骨资质**：五维雷达 + 天资总和；属性分页（基础/附加/特殊/元素/专精/武器，对齐 `content/attributes.ts`）；核心六维；能力等级十项。
- **签二·随身装备**：左 八部位 + 三套方案 + 均装等 + 悬停属性笺；右 行囊（容量、部位/品质筛选、整理、批量丢弃、分页、双击换装提示）——行囊并入装备签，换装动线自包含，主页面不再有常驻右栏。
- **签三·职业转职**：当前职业卡（图标、tier、职业 Lv + 经验条、可用技能类型、六维成长字母评级）；已修职业列表（可直接切换）；下一步可转方向（前置等级进度 + 转职书持有状态 + 可转/不可转）；「展开全树」页内展开完整 41 节点职业树（rank 行 + 连线 + 节点状态：当前/已修/可转/锁定），点节点出详情侧栏。不再用弹窗。

### 非功能

- **品级整卡分级**：品级驱动列传头部底色/边框/印章配色（丙灰/乙绿/甲蓝/地紫/天金，主角朱砂「主」，与装备品质色呼应），点将谱条目同步着色——稀有度一眼可辨。
- 自包含单文件 HTML + 内联演示数据与 JS 交互（页签切换、树展开、点将谱切换侠客）。
- 响应式：窄屏（<1100px）点将谱折叠为顶部横向选择条。
- 设计语言沿用：墨底宣纸、朱砂印、金漆、点将谱/列传措辞、同字体与 CSS 变量体系。

## 约束

- 只改 `docs/侠客页面重设计.html`（原型）与本文档；不动 `egg-jianghu/` 游戏代码，不提交 git。

## 方案与决策

### 决策标准

- 新内容（职业/转职/品级/根骨）在页面上有与其体量相称的位置。
- 换装、转职两条主要动线都在页面内自包含完成。
- 稀有度成为选将时的第一视觉信号。

### 选定方向

整页重排为两栏：左点将谱、右列传（常驻头 + 三页签）；行囊并入装备签；品级整卡分级；职业树个人视角优先、全树页内可展开。

### 选择理由

- 用户逐项选定：整页重排信息架构；列传内分页签；行囊并入装备页签；品级整卡分级；职业树个人视角优先、全树可展开。
- 分页签让三个体量都很大的板块（根骨/装备/职业）各自获得完整宽度，避免纵卷无限拉长；行囊并入装备签使「看已穿 → 挑包里 → 换装」动线最短；个人视角的职业签默认决策导向，全树仍可页内探索。

### 主要备选

- **纵卷列传、三栏不变**：板块纵排、转职树走弹窗；改动最聚焦，但职业/转职展示分量受限，未选。
- **双主栏、职业占一栏**：职业专区常驻右栏；转职体验最完整但页面信息量最大，未选。
- **行囊保留右栏常驻 / 移出侠客页**：前者与背包页重叠且页面过宽，后者换装要跳页，均未选。
- **品级仅印章标记**：最省事但稀有度的「新内容」感最弱，未选。
- **职业树常驻签内全展开**：一览全局但 41 节点在签内过挤，未选。
