# 侠客页复刻原版布局重设计

- 日期：2026-08-19
- 状态：已确认
- 视觉定稿：`docs/brainstorms/.visual/heroes-layout-v6.html`（同屏三状态：基础/装备/职业）

## 背景与目标

当前侠客页为左点将谱 / 中列传四段纵流 / 右行囊文字列表，1920×1080 下需滚动，且存在四个已确认问题：

1. 行囊列表数据源为全量 `state.inventory`，已装备物品带「已装备」标混入其中（应只显示未装备）。
2. 品质筛选与装备详情直接显示内部数值 0-9，不是原版《诸天刷宝录》的中文品质名。
3. 行囊 280px 栏宽下，每行「图标 | 名称+品质装等 | 部位标签」三段 grid 把最右部位标签挤出可视区。
4. 装备详情 tooltip 为浅宣纸底 + 棕灰小字（9-11.5px），附加词条评价值浅色发光，对比度过低看不清。

目标：照原版角色页布局重排为一屏放全，保留蛋蛋江湖暗金武侠皮肤，同时修复上述四问题。

## 核心需求

### 布局（一屏，1080p 基准不滚动）

- 三栏：左 点将谱（角色列表卡片+搜索+品级/脉系筛选+分页）/ 中 主内容 / 右 行囊；仅点将谱、行囊列表内部滚动。
- 主标签**横向**排列于中栏顶部：基础 / 装备 / 职业。

### 「基础」标签（三行）

- 第一行：角色头像 + 名字 + 品级印章 + 五维雷达图 + 五维资质数值列表（含原版式评级字母与「天资总和」）。
- 第二行「成长」：等级 EXP 条、当前职业 XP 条。（原版另有「天命」，本作无此系统，不放。）
- 第三行：左侧竖排子标签（基础/附加/特殊/元素/专精/武器）+ 双列属性行；各子页最多 16 项一次放全不滚动；零值属性半透明降噪。

### 「装备」标签

- 顶部只显示名字 + Lv。
- 中央全身立绘台座（当前为占位框，待用户生成全身立绘后替换）；两侧槽位左 5 右 4：左 武器/头部/护腕/项链/至宝，右 副手/身体/足部/戒指。
- 槽位图标加大、品质色底+边框；悬停出详情。
- 底部仅保留第 1/2/3 套方案切换与操作提示；去掉平均装等与穿戴计数。

### 「职业」标签

- 上半：当前职业（职业 ICON + 职业名 + 等级 + 五维成长参数 + 可用技能类型 + 经验条）。
- 下半：已修职业 3 列井字格，每格 icon + 职业名 + 等级。
- 底部居中「转职」按钮，打开现有全屏职业树弹层（弹层本身不改）。

### 行囊（修复 1/2/3）

- 文字行列表改**图标网格**（6 列）：格子底色+边框直接表达品质（原版风格），左上 NEW 角标、右下 Lv 角标。
- 部位筛选挪到右缘竖排：全 兵 副 冠 甲 腕 履 链 戒 宝。
- 品质筛选为顶部中文 chips（色点+中文名）。
- 数据源从全量 inventory 改为 `backpackEquipment()`，已装备物品不再入行囊。
- 顶部按钮：整理、按等阶售出；底部分页与容量计数。

### 品质中文名（修复 2）

按原版名表（用户从原版「按等阶销毁」界面确认），升序：

| 档 | 名 | 色 |
|---|---|---|
| 0 | 粗糙（暂拟，原版下拉无此档名） | 灰 lightgray |
| 1 | 普通 | 白 |
| 2 | 精致 | 绿 lightgreen |
| 3 | 优秀 | 蓝 lightblue |
| 4 | 不朽 | 黄 |
| 5 | 绝世 | 品红 fuchsia |
| 6 | 逆天 | 橙 orange |
| 7 | 神物 | 红 red |
| 8 | 圣阶 | 粉 deeppink |
| 9 | 创世 | 青 aqua |

- 全链路统一：行囊筛选 chips、格子底色、装备槽、详情 tooltip、售出弹窗。
- 现有 `--q-5…--q-9` 色序与原版不同（青色档原版在最高位 q9，我们当前在 q5），实现时按上表调整。

### 按等阶售出（替换批量丢弃）

- 点「按等阶售出」在行囊区弹下拉：普通及以下 … 创世及以下共 9 档，各档用品质色。
- **点某一档立即售出**所有品质 ≤ 该档且未装备、未锁定的装备；无确认按钮、无件数预估；点击弹窗外任意区域收起。
- 售出后发战报式提示（售出 N 件 · 得铜钱 X）。
- 售价按原版物品买卖价格公式：`max(round((修正系数×10)×(10+物品等级)×2.5^品质), 1) × 0.4`，计入当前位面铜钱（0.4 为原版卖出修正系数，实现时对照证据核验）。

### 装备详情 tooltip（修复 4）

- 深墨底 + 金边，名称用品质色；词条名米色、数值金色高亮；附加词条评级色保留但保证对比度。
- 字号整体上调至 12-14px 级。

## 约束

- 皮肤保持蛋蛋江湖暗金武侠（ink/金/宣纸/朱砂变量），不引入原版青绿科技风。
- 不改数据与机制：品质 0-9 十档、附词条条数、装等公式、掉落规则均不动；仅展示层 + 新增售出功能。
- 转职树沿用现有弹层，不重做。

## 方案与决策

### 决策标准

- 布局结构以原版《诸天刷宝录》角色页为准（用户明确要求照原版抄）。
- 一屏可见、正文 ≥12px、四问题全部修复。

### 选定方向

v6 视觉稿：横向主标签 + 三段式基础页 + 台座装备页 + 井字格职业页 + 图标网格行囊 + 品质中文名 + 按等阶售出下拉。

### 选择理由

用户确认通过。演进过程：A 三栏压缩（密度高、字更小，打回）→ C 自绘页签 v2（解决了属性容量但观感不佳，打回）→ v3 起复刻原版结构，v4 接入原版品质名、v5 简化售出交互、v6 定稿。

### 主要备选

- 三栏压缩：靠缩小字号腾空间，与「字体大一点」冲突，排除。
- 自绘页签布局：不满足原版观感，排除。
