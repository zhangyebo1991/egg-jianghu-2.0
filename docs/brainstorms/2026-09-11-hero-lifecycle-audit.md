# 角色阶段定位、替换节点与长期价值核对

后续实施：[阶段分层与确定兑换 V2](2026-09-11-hero-placement-v2.md)。用户已确认先实施阶段／用途分层和原版兑换，高级池暂不开放；本页保留静态研究证据及未实测边界。

日期：2026-09-11。状态：完成全量静态证据核对；**尚未测定逐人的实战淘汰关卡，不发布新的高级稀有名单**。

用户纠正：吕布、华佗属于前期使用、中期会换下的角色，不应因四命格组合而划入高稀有层。上一版角色分层与抽池实现已回退；当前仅按用户要求恢复赵云福利码，提交`753af59`。

## 1. 这次改变的判断顺序

先回答角色在什么阶段能拿到、当时能做什么、多久会遇到可行替代，再判断培养回报及退队后的用途。命格是其中一项证据。

| 核对项 | 必须使用的依据 | 不能替代它的东西 |
| --- | --- | --- |
| 获得阶段 | 章节、声望、贡献／材料来源、特殊入口实际开放条件 | 文学名气、声望高低直接等同稀有度 |
| 刚获得的战斗用途 | 当前位阶已生效效果、已学职业与技能、装备条件 | 把四命格全部视为开局可用 |
| 替换窗口 | 同岗位替代可获得且培养追平时，对比输出、治疗、存活、循环 | 后章角色、总资质更高就宣布全方位更强 |
| 培养回收 | 转职书、职业经验、SP和材料支出，装备可复用部分与时间成本 | 新角色裸号优于旧角色满培养的假对比 |
| 退队后用途 | 实际生产岗位、主角改命解锁、成本与替代来源 | 有“工作效率”词条就当已有账号收益 |
| 高级稀有资格 | 跨阶段持续有效、或已兑现且难替代的长期专用收益 | 某章强、四阶系数高、命格ID独有 |

**获取晚也不是高级稀有的充分条件；早期角色也不能一律判废。** 可以是前期战斗过渡，同时有后期生产／解锁用途，这两份价值必须分开。

## 2. 吕布：不再按高级稀有投放

- 原版第1章武馆、声望4、1600000位面货币；这是前期高门槛角色，不等于终局主力。
- 勇／智／体／敏／精为68／10／48／54／23。现在福利码赵云开局确定获得，对应71／33／47／73／27。
- 在相同等级、职业、装备、技能与皮肤附加均相同的假设下，仅资质乘区，赵云物攻为吕布的171／168≈1.018倍，速度为173／154≈1.123倍；这些不是完整DPS倍率。赵云体47低于吕布48，不能说五维全压制。
- 原版吕布第一命格物理增伤系数60，赵云为100；吕布四阶才有的斩神，赵云二阶已有。同天命阶下可比较单条属性，但不能据此越过命石成本与槽型差异。
- 吕布的暗蚀、嗜血是黑暗与吸血方向，必须匹配对应技能／敌人才能体现收益；这可以解释某个专门用法，不能自动撑起广泛的长期稀有定位。
- 四命格均有其他持有者；锻造3也不是长期独占，赵云锻造4，第9章妮拉索尔和第11章莫林铁须锻造5。

结论：接受玩家“前期过渡”的定位，撤销V1名侠／章节池建议。本作已有免费赵云后，需要先证明吕布的额外投入在目标玩法中值得，不能把他放进数周积累才能抽到的高稀有池。具体哪章换下仍需阵容、培养与战斗证据，不能从上述比值直接推出“第X章淘汰”。

## 3. 华佗：早期治疗投资与后期奶位分开

- 原版第1章蜀国、声望4、80000贡献。智56、敏38、精68。
- 一阶医仙支持医术方向；二阶仪器增伤并非所有治疗技能都吃，三阶组装是合成工作效率，四阶济世才是高系数治疗加成。原版四阶解锁需要300级及前置槽／转生材料，不能将其视为招到即有。
- 艾莉丝第4章第一命格就是治疗加成；米娅拉克斯第9章第一命格也是治疗加成且智58／敏52；神裔之女第12章一阶治疗、二阶医术。它们提供不同阶段的对照对象，但各自防御、技能适配、培养投入不同，尚不能指定某人为严格替代。
- 更晚治疗专门角色的兑现位置更集中：观音菩萨二阶已有同一济世；赫拉一阶济世，三阶冷却、四阶医术；毗湿奴一阶医术、二阶济世、三阶冷却。副本／圣魂渠道的确切开放时点未核实，不能用神系最终形态冒充中期替代。
- 华佗四命格均非独有。组装同ID在婴宁二阶、叶清婉一阶已出现；“合成4＋组装”应核对合成岗位实际收益后再评价收藏投入。当前本作没有核实到这条生产结算链。

结论：接受玩家“前期治疗过渡”的定位，撤销V1传奇／章节池建议。中期换下奶位不等于角色永久无用，但未核实的合成价值也不能重新包装成传奇价格理由。精确换人关卡暂不填写。

## 5. 当前本作与原版不能混用

- 当前所有招募角色以白丁起步；职业、武学需要培养。`src/domain/careers.ts`中转职检查前置职业等级并消耗职业书，新职业从1级开始。原版初始职业仅用于研究方向，不代表本作已经配好技能。
- `src/combat/stats.ts`先按角色等级计算基础核心值，叠加资质、装备、技能、皮肤并应用职业系数。决定强度的是完整配置，原品级不会自动提供一个“传奇倍率”。
- `src/combat/engine.ts`的治疗可按生命或法攻结算，并受治疗加成与受疗效果影响。不能只拿精或总资质比较治疗量。
- 当前未接入原版完整命格／命盘／转生属性链。原版四阶才能兑现的收益，既不能当前收费，也不能把裸面板测试当作原版终局强度评测。
- 能力白板、培养和装备加值合计上限5。当前核实消费端：计略用于`src/domain/faction-agent.ts`的势力代理收益，商业用于`src/domain/city-shop.ts`员工经营。其余能力面板有显示，不等于对应生产系统已有收益。
- 当能力均可培养到上限时，高白板可能体现的是省培养成本，不一定是最终收益更高；需核对本作相应培养入口是否存在。

## 6. 全量覆盖与证据等级

[逐人表](2026-09-11-hero-lifecycle-audit-roster.md)与[结构化记录](2026-09-11-hero-lifecycle-audit.json)覆盖：

- 193条原版记录：131章节、28副本、28神系、赵云1、主角1、占位4。
- 30名本作酒馆记录；有效伙伴共218，未把储备角色全部实装。
- 原版772个命格位置：解锁等级／位阶、同ID持有者、同属性且不低系数的其它来源、独有性。
- 每人原获得条件、透明的两项资质比较对象、五维均不低的比较对象、3级以上能力及替代来源。

自动比较只用于找出下一轮应测谁，不给稀有度打分。两项资质占优不代表存活或技能循环占优；五维均不低也没有纳入命盘与成本。副本的“映射章节”沿用研究表，明确不作为已核实开放顺序。

原版基线为本机`../诸天刷宝录/_analysis`的1.2.2.0逆向快照。本轮验证js、mg、ms、sx、mp、mc、data、c3runtime的8份SHA256均与研究证据相符，并逐项对比193条名字与965个五维值。当前package.nw此前记录的因陀罗、芙蕾雅、共工三项差异继续保留，不把基线称为当前发行版全量真值。
