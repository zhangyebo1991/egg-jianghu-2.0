# 「氪金武侠」玩法方向设计（蛋蛋经济 + 战斗新玩法）



* 日期：2026-09-11

* 状态：方向探索（待裁决）

* 关联：`docs/蛋蛋江湖2.0_设计文档.md`、`docs/武功重设计方案/00-总纲.md`、`docs/诸天刷宝录_属性与战斗机制研究.md`

## 0. 设计意图



1. **去诸天化**：战斗新玩法不再从《诸天刷宝录》找参考，改为原创主题驱动。既有 ATB / 能量 / 冷却 / 18 乘区公式 / 阵型作为数值地基**原样保留**（结构不变量），新玩法只在其上做加法。

2. **主题 = 氪金武侠**：把现代手游的 "付费体系"（VIP、首充、月卡、抽卡、保底、648、弹窗）全部做成**游戏内玩法**—— 付费货币「蛋蛋」全靠玩家在游戏里赚，赚到后像真・氪金玩家一样挥霍。

3. **一句话定位**：*人人都笑氪金怪，人人都是氪金怪。* 江湖最狠的不是武功，是钞能力 —— 而钞能力是打出来的。

4. **数值纪律**：蛋蛋带来的所有战斗增益**只落在现有 18 乘区 / 属性 / 状态 / 服务上**（最终增伤、受伤害、速度、能量回复、暴击、护盾、复活、易伤等），不新增失控乘区。讽刺的是 "充值武学理当更强"（同阶威力略高），但强度差距封闭在可控范围，不崩数值。

## 1. 核心支柱



| 支柱       | 含义                                        |
| -------- | ----------------------------------------- |
| 钞能力即战斗力  | 蛋蛋能 "购买" 即时战斗效果：氪金绝技、悬赏、战中服务              |
| 劳动即氪金    | 蛋蛋 100% 由玩法产出：挂机、任务、活动、排行、经营              |
| 全套付费玩法复刻 | VIP / 月卡 / 首充 / 十连 / 保底 / 弹窗全部做成可玩内容（讽刺点） |
| 数值不崩     | 蛋蛋增益全部映射现有乘区 / 属性，强度差异可控、可校准              |

## 2. 蛋蛋经济（总览）

### 2.1 账本裁决



* **统一蛋蛋**（跨场保留，兼作养成货币与战斗货币），不拆双账本。

* 战斗内消耗由**预算开关 + 技能冷却 + 单场上限**三重约束，防止 "囤币一波流" 破坏挂机节奏：


  * 每个蛋蛋绝技有冷却（ms），且**每场战斗每个蛋蛋绝技最多触发 N 次**（默认 2 次）；

  * 玩家可在设置中开关 "战斗支出预算"：`勒紧裤腰带（0 支出）/ 小费（每场≤10）/ 火力全开（每场≤30）`。

* 这样玩家每天面对的核心选择是：*这笔钱是存下来抽卡 / 升 VIP，还是留给战斗绝技救急 / 冲榜？* —— 这就是挂机游戏里稀缺的 "预算管理" 决策。

### 2.2 产出（来源，全部玩法内）



| 来源        | 说明                                  | 相对量级（初值，待校准）        |
| --------- | ----------------------------------- | ------------------- |
| 挂机战斗掉落    | 普通敌人概率掉落，受 "总掉落率加成" 影响；Boss 必掉      | 普通 1%/ 敌，Boss 5\~20 |
| 每日 / 每周悬赏 | 江湖悬赏任务板（已有任务系统复用）                   | 日 300\~500          |
| 成就 / 图鉴   | 首次达成一次性发放（已有成就位点）                   | 一次性 50\~2000        |
| 排行榜结算     | 无尽幻塔 / 通神天梯 周结算（已有进度复用）             | 周 200\~2000         |
| 门派任务      | 势力悬榜 / 任务（已有势力系统复用）                 | 中期稳定                |
| 城市经营      | 商号 / 科技产出（已有城市系统挂接）                 | 后期                  |
| 聚宝盆       | 蛋蛋理财：投入→按日回报（回报率 < 100%，限定总额，防通缩滥用） | 理财型                 |
| 限时活动      | 节日 / 版本活动                           | 波动                  |

**锚点**：目标日均蛋蛋收入 ≈ 1000\~1400（≈ 一张周卡价格）。玩家每天在 "续月卡 / 存钱抽卡 / 升级 VIP / 留战斗预算" 四者间取舍，蛋蛋永远不够花 —— 这正是讽刺的本体。

### 2.3 消耗（sink）



| 消耗           | 说明                                          |
| ------------ | ------------------------------------------- |
| 金主令（VIP）     | 累计消费蛋蛋升级，提供战斗 / 挂机 / 服务特权（长线最大 sink）        |
| 月奉令（月卡 / 周卡） | 周期性 buff：全队能量回复 + 1、挂机产出 + 20%、战斗蛋蛋产出 + 1 等 |
| 商道武学         | 蛋蛋购买 + 升级的新武学目录                             |
| 战斗支出         | 蛋蛋绝技、悬赏、战中复活（预算开关控制）                        |
| 秘宝盲盒（抽卡）     | 武学 / 装备 / 至宝池，带保底（讽刺 "官方概率"）                |
| 服务           | 一键强化、代练托管、扫荡、扩仓、洗练                          |
| 外观           | 皮肤 / 称号 / 头像框                               |

## 3. 战斗新增机制（核心玩法，均基于现有引擎）

> 落地标注沿用武功重设计方案口径：【现有】改数据即可；【扩展】需引擎小改。

### M1 蛋蛋绝技 —— 消耗蛋蛋的武功【现有引擎：damage/heal/shield/revive + 新资源】



* 新增武功类型 "商道・绝技"：**消耗蛋蛋而非能量**（能量照常参与其他武功循环）。

* 数值基准（对照现有换算：单体直接伤害威力 1.0 为基准；势力武功威力 `0.8+阶段×0.35`）：


  * 「氪金一击」：5 蛋蛋 / 次，单体威力 **2.2**（≈ 同阶能量武功 1.5 倍，讽刺 "充钱更猛"），冷却 3000ms，每场上限 2 次

  * 「钞能力护体」：8 蛋蛋 / 次，全队护盾 = 施法者法攻 ×1.2（复用护盾公式，上限 = 最大生命 100%），冷却 6000ms

  * 「以钱赎命」：15 蛋蛋 / 次，复活一名阵亡队友至 60% 生命（复用复活公式），冷却 30s

  * 「氪金风暴」：12 蛋蛋 / 次，群体威力 1.4（对照群体基准 0.5\~0.65），冷却 8000ms

* **实现面**：`combat/types.ts` 加战斗资源字段（wallet/budget），`engine.ts` 结算蛋蛋消耗，`skill-ai.ts` 增加 "预算不足则跳过" 判定，`skills.ts` 加 4 门数据，UI 战斗页在能量珠旁显示 "钱包 + 预算"。

* **设计意图**：蛋蛋绝技把 "能量循环" 外的第二决策维度带进战斗 —— 平时自动打，关键时刻 AI 按预算花小钱办大事。选择哪个绝技、开多少预算，是 build 的一部分。

### M2 悬赏击杀 —— 花钱买人头【扩展：目标优先级 + 掉落加成的组合】



* 战斗外 / 战中可对波次内指定敌人下达 "悬赏令"（消耗蛋蛋，如 20 蛋蛋 / 目标）：


  * 我方 AI 目标优先级改为**优先集火悬赏目标**（修改 `selectAttackPrimary` 的优先级输入，不动 AI 结构）；

  * 击杀悬赏目标时额外掉落蛋蛋（50\~150，高于成本，鼓励 "花小钱赚大钱"）。

* **风险与护栏**：悬赏目标存活 30s 未死则悬赏作废（钱不退，讽刺 "悬赏失败不退款"）；每波最多 1 个悬赏目标，防止无限刷。

### M3 金主位 —— 阵营经济位【扩展：新槽位概念 + 现成 buff/debuff】



* 每场战斗从队伍中指定 1 名侠客为 "金主"（阵型 UI 打 "金" 标）：


  * 金主存活时，全队获得「贵人相助」：每 30s 自动触发小额护盾或回能（复用现有 buff 机制）；

  * 金主阵亡则全队挂「资金链断裂」：最终减伤 / 速度 -15%，持续至战斗结束或金主复活（讽刺 "公司离不开金主"）。

* **实现面**：不需要新资源条，本质是一个带死亡惩罚的定位 buff。金主变成需要保护的战略位 —— 与现有 "护卫" 类武功形成协同（护卫金主 = 保护全队增益）。

* **设计意图**：把 "谁当金主" 变成站位 / 配队决策，与阵型（3×5）和护卫 / 复活类武学产生组合关系。

### M4 战斗预算 —— 自动战斗支出策略【现有引擎：设置项】



* 玩家设置三档：`勒紧裤腰带（0）/ 小费（≤10/场）/ 火力全开（≤30/场）`，AI 在预算内释放蛋蛋绝技。

* 预算按每场战斗重置（钱包余额不扣，扣的是 "本场预算额度"；蛋蛋在触发时扣除）。

* **设计意图**：这是挂机游戏里罕见的 "运营策略" 决策 —— 冲榜 / 卡关时火力全开，攒钱期勒紧裤腰带。也是蛋蛋 sink 的流量阀。

### M5 战斗服务（战前 / 战中弹窗）【现有引擎：服务动作】



* 战斗中可弹出 "快捷服务"（可关，讽刺弹窗广告）：


  * 「复活服务」：蛋蛋立即复活一名阵亡侠客（与以钱赎命同效果，无冷却限制，但价格 3 倍，讽刺 "急救贵"）

  * 「一键续命」：战斗中立即恢复全队 30% 生命（1 次 / 场）

* 战前服务（养成侧）：


  * 「代练托管」：离线挂机收益 ×2，持续 N 小时（蛋蛋付费）

  * 「一键强化 / 洗练」：跳过材料直接强化 / 洗练装备（复用现有装备公式）

  * 「扫荡」：已通关关卡直接结算收益

* **设计意图**：服务的本质是 "用蛋蛋买时间 / 便捷"，不产出超模数值，避免破坏养成平衡。

## 4. 养成与商店

### 4.1 商道武学（蛋蛋武学树）



* 新增武学目录 "奇门・商道"，蛋蛋购买 + 升级，效果全部映射现有乘区 / 属性：



| 武学（暂名） | 类型 | 效果（映射现有）                      | 引擎落地                           |
| ------ | -- | ----------------------------- | ------------------------------ |
| 奇货可居   | 被动 | 挂机蛋蛋产出 +20%（非战斗）              | 现有（产出公式挂接）                     |
| 钱能通神   | 被动 | 最终增伤 +5%/ 级                   | 现有（finalDamage）                |
| 和气生财   | 被动 | 受所有伤害 -3%/ 级                  | 现有（finalReduction/receivedAll） |
| 一掷千金   | 主动 | 消耗蛋蛋，群体 "易伤 +20%"debuff 8s    | 扩展（复用受伤害乘区，需易伤状态或近似）           |
| 财大气粗   | 主动 | 消耗蛋蛋，全队 "狂暴"：攻速 / 威力提升 15%，8s | 扩展（速度 / 威力 buff）               |



* **数值纪律**：商道武学的每一项都必须能对应到现有 `DamageMultipliers` 的某个字段或现有状态，不新增乘区。这样平衡可审计、可复算。

### 4.2 月奉令（月卡 / 周卡）



* 购买后生效 N 小时（或 N 场战斗）：全队能量回复 +1、挂机产出 +20%、战斗蛋蛋产出 +1。

* 到期弹 "续费提醒"（幽默文案："您的月奉令已到期，侠客们失去了尊贵的打斗体验。"）

* 作用：蛋蛋的**周期性 sink**，保证 "永远不够花"。

### 4.3 金主令（VIP）



* 武侠化分级：金主令・壹品「江湖新秀」→ 陆品「钞能力宗师」→ 拾品「富甲天下」。

* 累计**消费**蛋蛋升级（讽刺：消费不是持有）。特权示例：


  * 战斗：队伍上限 + 1、能量回复 + 1、战斗预算上限提升、战斗蛋蛋产出 + 1

  * 挂机：离线时长上限、掉落率、代练折扣

  * 服务：扩仓、一键强化解锁、弹窗关闭权

* 作用：长线最大 sink，给 "消费行为" 一个成长回报。

### 4.4 秘宝盲盒（抽卡）



* 蛋蛋抽 "武学 / 装备 / 至宝盲盒"，**公示保底**（讽刺官方概率）：每 99 抽必出绝品。

* 保底计数写入存档，可审计；不改变现有掉落体系，只提供一条**蛋蛋换养成进度**的通道。

* 讽刺细节：十连时弹 "本阁已公示全部概率，如有异议请联系知客僧（客服从不掉线）。"

### 4.5 外观 / 称号



* 皮肤、称号（"纯白嫖通关"" 一掷千金 "）、头像框。纯外观，不涉数值。

## 6. 数值校准建议



* **初始锚点**（全部标注为 "设计初值"，上线前用现有测试体系复算）：


  * 挂机蛋蛋掉落：1%/ 敌（受总掉落率加成），Boss 5\~20；

  * 日均收入目标 1000\~1400（≈1 张周卡）；

  * 周卡 1000 蛋蛋 / 7 天；月卡 3000 / 30 天；

  * 金主令升级成本曲线：从 500 起步、指数递增；

  * 战斗绝技价格：5/8/12/15 蛋蛋，单场预算档位 0/10/30。

* **验证方式**：用项目现有 `tests/` 体系补：


  * 蛋蛋绝技的伤害 / 护盾 / 复活数值与现有公式并排断言；

  * 预算档位下 AI 实际消耗 ≤ 档位上限（skill-ai 单测）；

  * 悬赏击杀的期望收益 > 成本（防 "亏本悬赏" 与 "无限刷" 双向验证）；

  * 产出曲线模拟：10 万次挂机掉落的蛋蛋收入分布（可复用 campaign-loot 的随机源固定机制）。

## 7. 实施分期



| 阶段            | 内容                                              | 改动面                                                                  |
| ------------- | ----------------------------------------------- | -------------------------------------------------------------------- |
| **P0（玩法验证）**  | 蛋蛋绝技 M1 + 预算开关 M4 + 2 门商道武学                     | combat/types + engine + skill-ai + skills 数据 + 战斗页钱包 UI + 设置页；存档 v20 |
| **P1（经济管线）**  | 蛋蛋产出（掉落 + 悬赏 + 成就）+ 月奉令 + 金主令 1\~5 品 + 秘宝盲盒（保底） | 掉落管线、任务板、商城页、存档字段                                                    |
| **P2（组合与长线）** | 金主位 M3、悬赏击杀 M2、战中服务 M5、商道武学树、聚宝盆、排行结算           | 阵型 UI、AI 优先级、服务框架、排行榜                                                |

**P0 验收**：一场 10 波战斗中，玩家能看到钱包增长、AI 在预算内花蛋蛋放大招、预算用尽后自动停手；数值与现有公式并排断言通过；旧存档不迁移（沿用 "新档限定" 方案，与至宝 / 神界体系一致）。

## 8. 开放问题（待玩家裁决）



1. **讽刺尺度**：全盘玩梗（连新手引导都做成 "氪金教学"）vs 点到为止（系统是正经的，文案玩梗）？推荐：**玩法正经、文案玩梗**—— 讽刺的强度来自 "规则本身很严谨"，而不是满屏段子。

2. **蛋蛋绝技是否允许战斗中手动释放**：自动（挂机纯粹）vs 保留 1 个手动按钮（类似现有 "绝招手动 / 自动" 设置）？推荐：沿用现有自动战斗哲学，只做预算开关，不做手动。

3. **P0 范围**：先做战斗机制（M1+M4，纯玩法验证）还是先做经济管线（产出 + 商店）？推荐先 M1+M4，因为它是 "自己的玩法" 的核心，经济管线本质是给玩法供血。

4. 蛋蛋绝技的 "每场上限 2 次" 与 "冷却" 双重约束是否足够，或需要引入 "单场消耗上限" 硬顶（预算档已隐含）—— 落地时按测试数据再定。
