▶ 📜 设计说明 · 核心循环与系统设计意图（点击展开 / 收起）

核心循环：「挂机战斗 → 获得经验/银两/掉落 → 招募侠客、学习武功、强化装备 → 推关解锁新城市与更强收益 → 更强的队伍挑战更高关卡」。战斗全自动进行，玩家的乐趣来自战前Build搭配（阵型前后排、每个侠客20格已学武功池与职业标签匹配）与战后资源分配（招募谁、学什么、强化哪件）。

职业标签体系是本作的深度核心：6条职业路线各5阶，进阶后累积「剑一、剑二……」职业标签；武功学习校验标签而非等级，让"进阶"直接决定"能学什么武功"，形成清晰的成长目标与收集驱动。每个侠客最多学20门武功，战斗中按已学顺序循环释放、CD 未好则普通攻击——武功池的广度与等级就是战力本身。

关卡即世界：30个大关卡构成江湖地图，每个大关卡内部包含「10个小关卡 + 本章城市 + 驻扎派系」三位一体：小关卡产出挂机收益；城市承接落脚点仪式感（客栈招募本章特色侠客、铁匠铺打造强化、武馆学通用武功）；派系按地域驻扎（如少林驻少林寺、丐帮驻襄阳城），提供日常任务→贡献点→兑换限定侠客与武功的活跃目标。离线收益、经脉升星、奇遇秘境、背包分别覆盖放置、长线养成、随机惊喜与资源管理。

原型说明：本页面为纯前端高保真原型，战斗为写死数据的自动模拟（血条扣减、日志滚动、武功特效提示、胜负循环），关卡两层视图、侠客详情、背包筛选均可交互，用于验证 UI 信息密度与玩法表达。
