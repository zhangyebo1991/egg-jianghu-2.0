# 角色核心属性等级字段核验（2026-09-10）

## 已确认的问题

原版 `基础核心属性` 的表达式 1026–1029 读取 `save.At(人物编号, 3, 1)`，该字段是角色等级，不是体魄。旧资质公式文档把 save 存档列号与 sx 属性编号混同，导致 `src/combat/stats.ts` 的基础值错误读取 `definition.aptitudes.constitution`，角色等级不参与六项基础属性计算。

本轮重新解码本机 `data.json` 和 `scripts/c3runtime.js`。原版等级文字、等级经验分母、经验进度条均读取同一字段，并将它传入 `等级显示` 或 `人物升级经验`，构成交叉证据。完整表达式、操作和源文件哈希见 `hero-core-level-audit.json`。后续已按用户授权修正业务代码，原研究阶段未改数值。

## 正确基础公式

- `B = 100 + 1.0095^(角色等级 × 10) × 5`
- 生命基础 `5B`，物攻/法攻基础 `B`，物防/法防基础 `0.5B`。
- 速度基础 `150 + 角色等级 / 4`。
- 天资仍参与后续百分比加成：生命 `(体+精)/2`，速度 `敏`，物攻 `勇`，物防 `体`，法攻 `智`，法防 `精`。
- 原版表达式 1039 先对基础、装备及百分比乘区的结果取整，再乘职业核心系数；旧文档的乘职业后取整描述也不准确。当前代码这一取整顺序正确。
- 白丁 4 级核心系数 `round((0.9 + 3 × 0.009) × 100) / 100 = 0.93`。

## 建议修复范围

将核心基础值和速度基础值中的体魄改为角色等级，保留正确的天资百分比、职业系数及装备等乘区；增加不同等级同天资、同等级不同天资的回归用例，更新依赖旧白板值的测试。不要通过提高主角资质或削弱邢道荣资质掩盖字段错误。


## 修复与验证

- 六项基础属性改读 `progress.level`，天资百分比、职业取整及装备/技能/皮肤加成保持原计算规则。
- 无存档结构变更，旧存档按已有角色等级重新计算面板；正在进行的战斗快照沿用现有更新时机，下次开战使用修正后的属性。
- 增加升级成长、体魄影响范围、截图两角色基础值回归；无额外加成的复算用例排除了自动拥有的免费皮肤。
- 53 文件、546 项单元测试，3 项开战/连续驻守/离页恢复浏览器回归，以及 TypeScript / Vite 构建通过；构建仍有既有大 chunk 提示。
