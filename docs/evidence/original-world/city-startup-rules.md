# 城市第一批：古玩店起步经营

本批范围：初始产业、闲置装备补货、店员任命、在线营业、现金入账、销售记录、进城剧情。用户随后要求关闭「秘境与神界」并升级存档号，最终使用 v19，新版本不读取或迁移 v17/v18。

## 原版证据

来源为本机《诸天刷宝录》1.2.2.0 `_analysis`，复用已有城市矩阵与公式生成结果。

`city-startup-runtime.json` 保存源文件指纹、事件 ID、分支路径、条件/动作和表达式；生成与只读复核命令分别为：

```text
node scripts/generate-original-world-evidence.mjs --city-startup-runtime
node scripts/generate-original-world-evidence.mjs --city-startup-runtime --check
```

## 本作操作与状态约束

- 原版包含任命时强制空闲的处理。本批改为明确提示并要求先下阵/卸任，禁止阵容、代理人、店员重复占用同一侠客；进行中的战斗也阻止任命。
- 使用现有 `GameSession.advanceRuntime` 的在线时钟，与战斗速度分离。离页继续，关闭游戏不补算离线收入。
- 货架、顾客、席位、接待进度、毫秒余量、评价、累计销售和最近十笔记录一并存档。交易立即结算；长时间无可售商品时仅累积至顾客上限，不空转大量 tick。
- v19 必须包含完整经营状态，拒绝缺失状态、负进度、重复装备、货架穿戴冲突、重复任职及未开放席位。旧 key 原样保留，新建/删档只操作 v19。
- 剧情为本作新增文案，不冒充原版剧情。三段引导可略过、重温；读完后按库存、店员和销售状态给出下一步提示，不发放教学装备或现金。
- 经营总览提供补货、任命、营业、地图定位及账簿；地图仍可进入同一古玩店经营界面。
- 「秘境与神界」从侧栏移除；应用路由与 `progression-*` 动作拦截，禁止直接进入和按钮结算发奖。原有底层规则与数据保留供后续真实挑战接入，旧浏览器用例改为验证关闭行为。

## 本批之外

土地买卖、建设、迁移、注册公司、主管与公司高管、设施、科研、月度财务结转和其他产业没有开放。当前财务展示为累计收支，不宣称已实现租金/月份结算。现有工作效率、装备、技能和能力数据由项目已有属性计算复用；本批不增加尚不存在的养成途径。

## 验证

- Domain：装备归属、容量、重复操作、任职互斥、价格、在线与离线、分段时钟、多席销售、剧情持久化及损坏存档。
- 浏览器：正常新角色经第一关真实战斗获得装备，将主角下阵后亲自看店，完成上架、任命、销售和重载；仅加速时钟，不注入物品/现金/通关结果。
- 界面：1440px 与 390px 下剧情、柜台和账簿截图，无横向溢出。
- 关闭回归：侧栏无秘境入口，直接路由回到江湖，伪造所有原奖励按钮不修改状态。

本轮全量单测 605 项通过；城市/地图/关闭入口 5 项 E2E 与启动、旧档、写入冲突等 13 项 E2E 分批通过（关闭入口用例在两批中重复）。TypeScript 与生产构建通过，构建仍提示既有大 chunk。

城市起步经营证据单独核验通过。额外执行 `evidence:world:check` 时，既有 `faction-runtime-evidence.json` 被报告过期；对 HEAD 中未修改的生成器执行相同只读检查亦复现，未重写该批无关势力快照。

城镇废案入口及路由已关闭，城市招募跳转独立势力页；旧城镇酒馆按钮也不再响应。势力页保留原有兑换与招募。
