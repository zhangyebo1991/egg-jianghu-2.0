# 原版技能图标接入

- 使用本机原版 `jn.json` 第 2 字段作为 `技能图标` 动画名；原运行时 SetAnim 证据见 skill-icons-runtime.json。按原图集第 0 帧提取，保留旋转和透明通道。
- 当前 376 个技能全部有可解析图片：338 个技能映射 283 种原版图标；38 个原表 iconKey=0 的召唤/灵兽等技能无专属图标，明确使用原版攻击图标兜底。详情及逐文件哈希见 skill-icons-assets.json。原版共用图标的技能仍共用相同图案。
- `node scripts/generate-skill-icons.mjs` 可重建 376 张无损 WebP（约 2.7 MB）及资产报告。非零图标键缺失时生成器报错，不静默配错图。
- 武学列表、携带槽位、传承节点及详情按 originalSkillId 使用原版图标；战斗技能名称旁使用相同映射。职业类别与本作心法图标不受影响。
- 验证：52 文件 543 项单元测试、构建、7 项武学与传承浏览器测试通过；已查看 1440px 和 390px 武学截图，图片正常且无溢出。构建仅有既有大 chunk 提示。
