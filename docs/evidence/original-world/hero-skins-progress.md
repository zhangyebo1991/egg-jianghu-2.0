# 侠客立绘与皮肤模块

## 范围

- 原版 `js.json` 的 193 角色及 `hh.json` 的 267 皮肤均从本机原包图集提取，共 460 张 WebP（约 19.6 MB）。按动画名称匹配第 0 帧，处理图集旋转，不以姓名近似配图。
- 主角及有 sourceId 的势力侠客使用对应原版立绘；本作郭靖、穆念慈等自创名录不在原版，继续使用各自已有专属图。装备页、点将谱和战斗头像随皮肤切换显示；窄屏装备页也显示角色。
- 新增皮肤页签及装备页入口，支持查看专属皮肤、当前外观、星级、加成、原版获取来源，以及切换和升星。
- 2026-09-10 用户明确暂不做兑换。本次已移除新增幻化石兑换 UI、动作及测试，不改原有势力兑换；保留已有 unlockedSkinIds 对应皮肤所有权。未开放途径的皮肤只展示，不能使用或升级。幻化石仍为 materials['10']，后续可接获取途径。

## 规则和存档

- 原版函数证据在 hero-skins-runtime.json；素材映射和源哈希在 hero-skins-assets.json。
- 本地资源中的免费幻型随对应角色开放；已拥有加成累计，切换和恢复本体不移除加成。
- 同角色同品质的外观共用星级、同属性加成只计算一次，避免男女版本重复叠加；每项增幅为品质 × 0.25 × 星级，最高 10 星。升星消耗当前星级 × 品质平方个幻化石。
- 加成进入六项核心属性计算及战斗快照；受现有整数取整影响，低等级角色一次升星不一定让显示整数增加。
- HeroProgressV10 新增可选 selectedSkinId 和 skinStars；缺省本体 / 1 星，不提高存档版本、不清空旧档。保留序列化字段并验证星级范围。
- 校验角色归属、招募、所有权、材料不足及满星边界；战斗和重开等待期间禁止切换/升星，即使绕过按钮 disabled 仍拦截。

## 复用与验证

- `node scripts/generate-hero-skins.mjs` 从同级原版 `_analysis` 表和 `.nw` 图片重建数据及立绘，需要 Python 与已有 sharp。
- 单元测试覆盖所有 460 张文件、映射、存档、已有兑换记录接通、升星扣费、同品质共享、上限和实际战斗属性。
- 页面测试 hero-skins.spec.ts 覆盖角色换图、皮肤切换、升星、刷新持久化、战斗锁定及 1440/390px 视口。原版图集透明区域 RGB 有颜色杂讯，但 alpha 为 0；浏览器显示正常。
- 长列表使用资料区内滚动；装备底部按钮允许整组换行，避免页脚遮挡和按钮文字竖排。
- 本次功能尚未提交；遵循新目标，不扩大到完整原版兑换系统。
