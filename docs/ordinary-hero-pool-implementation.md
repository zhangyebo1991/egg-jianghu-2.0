日期：2026-09-12。用户授权实施；本页替代V2中“尚未开放普通池／131人均可兑换”的获取范围说明，不恢复旧稀有度分层或设计分析界面。

## 已确认规则

- 只取需要做任务、使用贡献的正式势力；武馆等位面货币招募势力不入池。每个势力取声望门槛最高的一人，并列时按现有招募名录顺序取第一人。
- 共29人，第一世界为王异、关羽、孙尚香。蜀国并列第二人诸葛亮继续兑换，吕布、华佗不入池。其余102名原版章节角色继续原门槛兑换；福利赵云保持设置福利码领取。
- 只有一个普通池，位于“商城”的首个区块。解锁世界即加入该世界的池角色，不再要求解锁其势力或达到原招募声望；旧世界未取得角色继续留池。
- 抽到即移除，旧存档已拥有者也自动排除，不覆盖培养；无重复、无心愿、无多档稀有度。
- 100蛋蛋一次，十次需先持有1000蛋蛋。侠客基础总概率1.2%，剩余角色均分；普通材料总概率98.8%，初晶矿石×2和灵风松木×2各占49.4%。
- 连续69次未出侠客，第70次必出。任意出侠客后重置；跨世界、离开商城、重载和导入导出不清零。取消旧280抽分档保底与560抽心愿保障。
- 单次实际概率正常为1.2%／剩余人数，保底时为100%／剩余人数。十次逐次结算，角色移除后重新计算；没有收益卡概率或数量加成。
- 十次途中抽空立刻停止，只扣实际次数。例如第一世界三人全部连续抽中，只扣300蛋蛋。空池显示“暂无可抽取角色”并禁用抽取，不继续花蛋蛋抽材料。未解锁世界还有角色时提示继续解锁；全世界集齐则显示已全部获得。

## 界面与存档

商城显示全部当前可抽角色及各自基础／本次概率，点击查看初始白丁1级的五维、六项战斗面板与十项能力。页面只展示玩法、概率和角色数据，不展示前期过渡／章节培养等设计分析。角色结果在池页展示，奖励弹窗仍只覆盖福利码。

势力名录的池角色改为“前往普通池”，同时领域招募函数拒绝旧兑换，不能通过旧按钮或调试招募绕过。没有删除名录源数据或重写已拥有者来源。

保持v19及现有存档key，仅增加ordinaryPoolMisses，旧档缺字段时默认0。计数必须为0～69的整数，损坏记录拒绝加载。角色剩余集合由世界解锁与已拥有状态计算，不另存一份易失配的池列表。

抽取前检查会话存档冲突并结算挂机蛋蛋；一批结果完成后才提交扣款与发奖，保存失败回滚角色、材料、余额和保底。无效或抛错随机源不会留下部分消费。已有角色培养、阵容、装备及福利码记录保持。
