# 蛋蛋江湖 2.0 · 水墨实装 UI 素材清单 v2

对应原型：`docs/UI高保真_v1.html`。对应实装：`egg-jianghu`。

这份清单用于交给图片生成 AI。原 `UI素材清单_v1.md` 中的 `hero-h1`、`hero-x0` 等是原型演示编号，**不要作为实际游戏角色的文件名**。实际角色、敌人、装备、技能、职业按游戏资源 ID 对齐。

## 交付位置和命名

所有新图放在 `egg-jianghu/src/assets/ink/`，按下文子目录保存。原图保留，禁止覆盖 `heroes/original` 等原始目录。

除背景外，图片可以交付 PNG 或 WebP；同名两种格式均存在时游戏优先 WebP。背景固定为 `ui/bg-battlefield.png`。新增图片后重新运行 `npm run build`，即可打包进网页和桌面版。未生成的图继续使用原图并临时去色；已有水墨图自动保留自身色彩。

配套文件 [`UI素材索引_水墨实装_v2.json`](UI素材索引_水墨实装_v2.json) 列出实际文件逐项映射，每一条包含原图 `source`、目标 `output`、尺寸、优先级和单图提示词。**批量生产以索引里的实际条目为准，不按编号范围猜测缺号。** 每次只生成一项，不拼接成图集或含多个小图的展示板。

## 统一美术方向

- 昼卷：宣纸暖白 `#ece5d3`，天空 `#f3edde`，松烟墨 `#1d1a15`。战场中部和顶部大量留白。
- 夜册：底色 `#191611`、次底 `#211d16`，亮部 `#e9e2cf`。头像和物品必须在深底上清楚可辨，避免黑色主体完全融入背景。
- 唯一饱和强调色：朱砂 `#c2402a`，面积不超过 3%。不用金色描边、宝石渐变、绿色发光、霓虹或西式金属 UI。
- 笔法：浓淡水墨、干笔飞白、克制的纸纹；轮廓准确，缩小后保留辨识度。
- 不生成文字、数字、角色名、品质星级、边框、印章、水印；这些由游戏叠加。透明图必须是真实 alpha，不可画棋盘格。
- 角色身份、年代、性别、物种、服饰和兵器以对应原图为准。十三位面还含现代、科幻和奇幻角色，不能全部改画为古装人类。

英文锚点：

```text
Chinese ink wash game art, shui-mo, dry brush and restrained ink diffusion,
monochrome pine-soot ink, warm rice-paper highlights, tiny vermilion accents,
clear silhouette, faithful to the reference character or object,
no text, no labels, no frame, no seal, no watermark, no neon, no gold trim
```

## 第二批：最先看到的侠客、敌人和装备（P1）

### 侠客圆形头像

路径：`portraits/hero_<原版角色ID>.png`。512×512，肩部以上胸像。

- 参照索引的原立绘保持身份；新绘胸像，不把全身立绘直接缩进头像。
- 面部放在画面中心稍上，人物主体落在中央 70% 安全圆内；周围留 12% 安全边距。
- 深墨底 `#191611`；浅墨和暖纸色勾出面部，轮廓在 28px、44px、62px 下都要清晰。
- 战场、行囊侠客列表、阵容名册和招募共用。头像不要带职业和品级印章。
- 推荐先做 `hero_1`（主角）与 `hero_165`（赵云），随后按首个解锁位面的实际人物逐批生产。其余身份通过 `source` 原图核对，勿按原型的演示人物替换。

提示词：

```text
以提供的游戏人物原图为身份参考，保留性别、年龄、面貌特点、发型和标志性服饰。
改绘中国水墨风肩部以上头像，脸部居中略偏上，中央七成圆形区域内完整呈现。
深墨背景 #191611，暖纸色表现受光面，墨线轻重有致，少量朱砂缨饰。
清晰五官，缩小到 44px 仍可辨认，不画边框、品级、名字、印章或水印。512x512。
```

### 敌人头像

路径：`enemies/zt_<怪物ID>.png`，召唤单位为 `enemies/zt_s<ID>.png`。512×512。

不要把索引中的怪物都改成人：原图为兽、鬼、机械、骑兵时保留对应种类。普通敌人轮廓简洁，精英和首领可增加冠饰、肩甲等辨识元素，仍遵守中央安全圆；等级和 BOSS 字样由游戏标注。

提示词：

```text
参考所给敌人原图，保留物种、时代、武器和身份，重绘水墨半身像或怪物特写。
松烟墨浓淡明确，眼部和主体受光面用暖宣纸色提亮，深墨底 #191611。
中央七成圆形安全区内呈现，姿态有威胁但轮廓简洁，无文字无边框。512x512。
```

### 装备图标

路径：`equipment/zt_eq_<图标ID>.png`。512×512。

同一图标 ID 可被多件装备复用，按索引生成一张即可。不根据装备品质自行改成另一种武器。

- 单件静物，中心主体占 75%，方向与参考一致。
- 深墨底 `#211d16`，底部 18% 不放关键细节，便于游戏叠加名称与等级。
- 项链、戒指、副手、至宝保留原物品种类，不能全画成玉佩。

提示词：

```text
以提供物品原图为形制参考，水墨游戏道具静物，单件居中，占画面四分之三。
深墨背景 #211d16，用淡墨、暖纸高光表现材质，干笔勾出轮廓。
底部留出 18% 非关键区域供 UI 覆盖。无文字、星级、金框或水印。512x512。
```

## 批次自检和接入

1. 每个文件的名称、路径与索引一致；PNG/WebP 二选一，切勿保留一个旧 WebP 又添加同名新 PNG。
2. 检查图片真实尺寸、透明图的 alpha、四周安全边距和缩略图辨识度。
3. 当前底图已接入；其余图可按批次落盘。不必等全量完成才查看效果。
4. 在 `egg-jianghu` 运行 `npm run build`；新图经 Vite 生成带 hash 的发布资源。网页和 Electron 均使用相对资源地址。
5. 验收 1440×900 和 390×844：头像圆形裁切不切脸，行囊底部名称不遮主要物品，夜册图标不融入黑底，人物立绘没有透明棋盘。
6. 本清单不要求重绘已退出主界面的旧位面大海报、金属面板、厚金边按钮；后续若再使用，另列对应实际入口。

索引可用 `node scripts/generate-ink-asset-manifest.mjs` 从当前原资源重新生成，不包含任何已生成新图的完成声明。
