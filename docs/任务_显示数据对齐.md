# 任务：角色属性面板「显示数据对齐」——《蛋蛋江湖2.0》对齐《诸天刷宝录》

> 供下次会话使用。用户提供的权威面板文档已存于 `docs/诸天刷宝录_角色属性面板_白板号.md`，**以文档值为准，不要靠猜**。

## 背景

- 蛋蛋江湖 2.0（`egg-jianghu/src`）属性体系基于《诸天刷宝录》sx.json（202 属性，sx 1-202，证据等级 A）。
- 已完成逆向落地：6 核心属性（指数模板）、暴击几率/暴击伤害、命中/闪避（比率公式）、技能冷却、吸血（战斗逻辑）、能量（sx28/29）。见 `docs/诸天刷宝录_资质面板公式_源码逆向.md`。
- 数据结构：`AttributeMap`（sx id → 值），`buildAttributeMap`/`panelToAttributeMap` 生成；`ui/heroes-page.ts` 已有按「基础/附加/特殊/元素/专精/武器」分组的属性面板（`ATTR_TABS`，已对齐原版分组）。

## 目标

让蛋蛋游戏界面显示的原版角色属性面板，与原版《诸天刷宝录》白板号面板**逐属性对齐**（属性集合、数值、显示格式、单位）。

- **权威基准**：`docs/诸天刷宝录_角色属性面板_白板号.md`（用户提供，白板号全量面板）。
- 原版面板参考链接：`https://www.doubao.com/chat/38437419031455234`（豆包对话，可能需登录；若不可达，以文档为准）。

## 已确认的偏差（需在本任务中修正）

### 1. 核心属性模板分配错误（stats.ts）
文档显示 **物攻 = 法攻 = 117**（同一 ×1 模板）、**物防 = 法防 = 58**（同一 ×0.5 模板）。
当前 `stats.ts` 是 **物攻 = 物防**（×1）、**法攻 = 法防**（×0.5）。**需交换物防/法攻的模板。**

### 2. 核心属性数值偏差（公式常数需校准）
| 属性 | 文档白板 | 当前公式 |
|---|---|---|
| 生命 | 580 | ≈564 |
| 速度 | 150 | 152.5 |
| 物攻 | 117 | ≈113 |
| 物防 | 58 | ≈113 |
| 法攻 | 117 | ≈56 |
| 法防 | 58 | ≈56 |

需按文档白板值反推校准（指数底数/系数/资质代入），并修正 stats.ts + damage.test/相关测试断言。

### 3. 技能学习（sx39）白板 = 0（原文档 1% 是命石影响，已纠错）
文档 §5 显示技能学习 1%，但该值是**命石影响**所致，**非角色固有基础**：
- sx39 走「特定属性统计function」**默认分支**（装备/技能/命石/命格/副官/幻化/灵兽/神位总和），无固有基础 = 0（见《资质面板公式_源码逆向.md》§9.2；sx39 不在特判分支 3/12/14/66/48/核心）。
- sx.json 的 sx39 默认 20 是词条基准，非面板基础值（同上 §8.4）。
- `c3runtime.js`「命石总属性function」确认命石按词条编号（sx id）授予属性求和进面板；白板号特殊页 16 项中仅技能学习 1%（其余全 0），正是指定命石的孤立效果。
- **蛋蛋落地：技能学习白板 = 0，不补 1%。**（原始任务描述「补 map[39] = 1」有误，勿执行。）

### 4. 显示集合核对
- 对照文档六/七/八节：元素（8 元素增伤/抗性）、专精（sx60-75）、武器掌握（sx92-101）白板全 0——蛋蛋 `AttributeMap` 缺失回退 0 即可，但需确认 `heroes-page` 的 `ATTR_TABS` 显示集合与文档面板**完全一致**（含生活技能 Lv0、熟练度 0/10万 等非 sx 数值）。
- 检查 `uiFlag` 过滤：原版按 `uiFlag` 决定面板显示，蛋蛋当前按 `ATTR_TABS` 的 category 过滤——需核对两套口径是否一致。
