标签体系说明

例：刀系路线 刀客(a) → 狂刀(a,b) → 刀皇(a,b,c) → 刀圣(a,b,c,d) → 刀神(a,b,c,d,e)。

跨系高阶武功可能要求双标签（如 刀c+内x），鼓励主副双修或依靠稀有「洗髓丹」重置职业路线。角色进阶不可逆，但可消耗洗髓丹退回初始职业重选路线。
