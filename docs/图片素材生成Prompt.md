# 蛋蛋江湖2.0 图片素材生成 Prompt 清单

武侠风水墨淡彩风格，共 72 张图，每张一个独立 prompt，已内含统一风格词，可直接单独复制使用。

## 使用说明

**风格统一的三个关键：**
1. 每条 prompt 末尾的风格词一字不改，原样复制
2. 同一批图使用同一个模型生成；支持 seed 的模型建议同类图固定同一个 seed
3. 每批生成后拼 contact sheet 对比，淘汰画风跑偏的图重新生成

**角色名不写入 prompt**：模型不认识金庸角色，且避免生成特定影视形象。全部用外貌描述，文件名与游戏内 id 对应。

**通用负面词（每类按需补充）：**

```
现代服饰，枪械，眼镜，动漫风，日系，油画，写实照片，3D渲染，赛博朋克，文字，水印，边框，模糊，低清，畸形，多余手指，多人
```

- 头像/敌人：直接用上面的负面词
- 场景：追加 `人物`
- 图标：追加 `人物，复杂背景`

**建议尺寸与导出：**

| 类别 | 生成尺寸 | 导出 | 说明 |
| --- | --- | --- | --- |
| 侠客/敌人头像 | 1024×1024 | 256×256 PNG/WebP | 宣纸底色，UI 用 CSS 圆形遮罩，无需抠图 |
| 世界场景 | 1920×1080 或 1344×768 | WebP（质量 80） | 江湖页世界卡缩略图 + 挂机页战场背景，一图两用 |
| 职业/武功图标 | 1024×1024 | 256×256 PNG | 白底可用 CSS 混合模式（multiply）融入面板 |

**建议文件命名（对应规划的 `src/assets/` 目录）：**

- 侠客：`src/assets/heroes/hero_guo_jing.png`，通用头像：`src/assets/heroes/generic_sword.png`
- 敌人：`src/assets/enemies/normal_1.png` / `elite_1.png` / `boss_1.png`
- 场景：`src/assets/worlds/world_01.png`
- 图标：`src/assets/careers/sword.png`、`src/assets/martials/sword_swift.png`

**推荐生成顺序（先铺底、后补全）：**
1. 职业通用头像 6 张 + 敌人 7 张（所有侠客/敌人立刻有图可用）
2. 世界场景 10 张（江湖页 + 战斗背景）
3. 酒馆侠客头像 31 张（按江湖卷分 10 批，每卷 3 张左右）
4. 图标 18 张
