# 卷八 · 姑苏

姑苏城外燕子坞，参合庄中慕容氏念念不忘复兴大燕，《天龙八部》的江南武林以「以彼之道，还施彼身」名动天下。此地水网纵横、人文荟萃，少林高僧、逍遥剑客、大理名医皆曾在此留下传说，《笑傲江湖》的辟邪剑影亦自江南传遍江湖。本卷武功以江南武林的精深博大为基调，强度对标第八卷。

## 少林（拳）

禅宗祖庭，武学渊薮，七十二绝技冠绝天下。刚拳线走外门硬撼之路，绵掌线走阴柔内劲之路，刚柔并济方是少林真传。
