# 卷九 · 聚贤庄

聚贤庄是《天龙八部》中乔峰血战群雄之地——中原豪杰齐聚于此设下英雄宴，乔峰以一己之力独战天下高手，降龙掌法纵横无敌，是全书至刚至烈的篇章。本卷以「刚猛与侠烈」为骨：丐帮降龙掌法在此达到巅峰，聪辩门下苏星河一脉以医术济世，渔樵耕读则以胡家快刀与血刀狂刀演绎刀道两极。品级整体步入上乘/绝学层次，与聚贤庄群豪毕集的规格相称。
