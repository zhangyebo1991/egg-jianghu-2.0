# 卷三 · 归云庄

> 本卷对应《射雕英雄传》中段：陆乘风归云庄聚太湖群豪、铁掌帮暗流涌动，武功已由初入江湖的粗浅路数过渡到各派正传；剧情向后呼应《神雕侠侣》绝情谷（公孙止金刀黑剑、裘千尺枣核钉）与万兽山庄（史家兄弟驭兽）一段恩怨。整体风格：刀光狠戾、驭兽奇诡、玄门清正，承上启下。
