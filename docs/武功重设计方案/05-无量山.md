# 卷五 · 无量山

> 《天龙八部》开篇之地：段誉误入无量山，于无量玉璧前窥见「神仙姐姐」玉像，得北冥神功与凌波微步，就此卷入江湖风雨。此卷以逍遥派遗迹为主线——天山折梅手、生死符、小无相功皆出于此脉；灵鹫宫剑宗分舵携越女、金蛇两脉剑法立威；万劫谷钟万仇一家以刀阵机关与奇毒自守。全卷武学分「内家」「剑」「暗」三路，讲究机缘与奇诡。
