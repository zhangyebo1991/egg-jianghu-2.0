# 卷二 · 嘉兴

> 嘉兴是《射雕英雄传》江南段的核心舞台：醉仙楼头烟雨楼畔，江南七怪与丘处机立约比武，太湖之上陆乘风、陆冠英父子统率群盗，水陆两路风云际会。本卷以「江南水乡」为底色——陆家庄刀法带水寨豪侠气，白驼山蛇毒自西域悄然东渐，古墓派遗世独立于江湖纷争之外。

## 陆家庄（刀）

太湖群盗之首，仙霞派陆乘风父子所创水寨基业。刀法承桃花岛武学余韵，又糅合水乡行舟搏浪之势，快刀如浪里穿梭，狂刀如潮头断岳。
