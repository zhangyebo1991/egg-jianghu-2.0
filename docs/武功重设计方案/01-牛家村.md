# 卷一 · 牛家村

> 江南嘉兴府外的寻常村落，却因郭啸天、杨铁心两家血案而拉开《射雕英雄传》的大幕。此处是玩家踏入江湖的第一站：全真教长春一脉在此传道，丐帮弟子沿街行乞，桃花岛的药香也随商船飘入村巷。武功品级以「粗浅」为主，偶见「寻常」，立意是大道至简、入门筑基。

## 全真教（剑）

玄门正宗，剑法堂堂正正。快剑一脉迅捷连绵，重剑一脉沉雄厚重，皆为全真入门至精进的正统路数（先天功、天罡北斗阵等镇教绝学不在本村传授，留待后卷）。
