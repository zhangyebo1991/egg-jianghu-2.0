# 卷六 · 风陵渡

风陵渡，黄河渡口，风雪夜归人。这里是《神雕侠侣》郭襄初闻「神雕大侠」之名的地方，也是蒙古大军压境、襄阳烽火的前沿。渡口对岸蒙古大营弯刀如林，丐帮弟子混迹草莽打探军情，而一灯大师门下渔樵耕读四人曾随师隐居江湖，悬壶济世。本卷武功以「军旅杀伐之气」与「乱世仁心」双线并行：刀掌刚猛见于军阵，医术药理存乎渡头。

## 蒙古大营（刀）

蒙古军阵中的刀法，一派是来去如电的刺客快刀（借古龙傅红雪拔刀之意），一派是冲锋陷阵的军中狂刀（终于金轮法王五轮大法）。

## 渔樵耕读（医）

一灯大师门下四弟子——渔、樵、耕、读，乱世渡头悬壶行医。疗伤线承一阳指救人之道（朱子柳更以书法合一阳指），药理线化琴棋书画四艺为控场减益之技。
