## 一、命名原则

1. **直接用原名**：使用金庸、古龙小说中的武功原名（如「亢龙有悔」「灵犀一指」）。
2. **门派对口**：势力名本身多为金庸门派（全真教、丐帮、桃花岛、白驼山、古墓派、大理段氏、天龙寺、逍遥派、灵鹫宫、明教、武当、峨眉、少林、星宿派、姑苏慕容……），优先选用该门派在原著中的武功。
3. **四阶递进**：每条分支线 4 门武功按修炼层次递进（初传→进境→真传→秘传），可用同一武功的招式/境界递进（如降龙十八掌各掌法），也可用同门由浅入深的 4 门不同武功。秘传阶段必须是该派镇派绝学。
4. **贴合分支风格**：分支标签决定武功气质——
   - 剑：快剑=迅捷连击 / 重剑=刚猛破甲（重剑无锋，大巧不工）
   - 刀：快刀=迅捷连击 / 狂刀=刚猛狂暴
   - 拳：刚拳=正面硬撼 / 绵掌=阴柔持续
   - 暗：影刺=爆发点杀 / 毒术=中毒减益
   - 医：疗伤=治疗护卫 / 药理=以毒攻毒、减益辅助
   - 内家：运气=内劲伤害 / 护体=防御增益
5. **借用他派**：门派原著武功不足以填满 8 门时，可从金庸十五部、古龙主要作品（楚留香、陆小凤、小李飞刀、绝代双骄、圆月弯刀、三少爷的剑等）中借用品味相合的武功，需在意境上说得通。
6. **通用武功**：城市通用武功选用江湖上广为流传的常见武功名（如太祖长拳、五虎断门刀），随世界卷数递进而愈发有名头。
7. **同名不同卷**：同一门派出现在多个世界时（如丐帮 ×3、全真教 ×2、逍遥派 ×2、大理段氏 ×2、灵鹫宫 ×2、渔樵耕读 ×2），高卷世界使用同门更高深的武功，避免低卷武功名重复出现。

## 二、新效果机制体系

> 现状引擎只支持：伤害 / 治疗 / 复活 / 净化 / 护卫 / 驱散，单体或群体目标，加上简单状态。
> 以下为扩展后的机制词汇表。每门武功的效果描述使用这些术语书写，并标注落地方式：
> - 【现有】引擎已支持，改数据即可落地；
> - 【扩展】需要战斗引擎新增该机制，落地工作量见第五节。

### 2.1 进攻机制

| 机制 | 说明 | 参数 |
|---|---|---|
| 连击【扩展】 | 一次施放分 N 段打击，每段威力按比例分配，段数可被闪避逐段判定 | 段数、各段比例 |
| 破甲【扩展】 | 使目标外功防御降低 X%，持续 T 秒 | 幅度、持续 |
| 破气【扩展】 | 使目标内功防御降低 X%，持续 T 秒 | 幅度、持续 |
| 易伤【扩展】 | 使目标受到的所有伤害提高 X%，持续 T 秒 | 幅度、持续 |
| 流血【扩展】 | 外伤持续伤害：每秒失去当前生命的 X%，持续 T 秒 | 每秒比例、持续 |
| 中毒【扩展】 | 内伤持续伤害：每秒失去最大生命的 X%，可叠 N 层，持续 T 秒 | 每秒比例、层数、持续 |
| 点穴【扩展】 | 眩晕：目标 T 秒内无法行动 | 持续 |
| 封穴【扩展】 | 沉默：目标 T 秒内无法施放武功（仅普攻） | 持续 |
| 迟缓【扩展】 | 目标行动条积攒速率降低 X%，持续 T 秒 | 幅度、持续 |
| 吸血【扩展】 | 造成伤害的 X% 转化为自身生命 | 比例 |
| 吸内【扩展】 | 造成伤害的 X% 夺取目标真气（化功大法、北冥神功类） | 比例 |
| 蓄力【扩展】 | 吟唱 X 秒（可被打断）后释放高额伤害（蛤蟆功类） | 吟唱时长、威力加成 |
| 狂暴【扩展】 | 自身生命低于 X% 时威力提升 Y% | 阈值、加成 |
| 破绽标记【扩展】 | 给目标挂上破绽，友方对其伤害加深 X%，触发后消失 | 幅度 |
| 击退/拉近【扩展】 | 改变目标站位，打乱敌方阵型 | 方向 |
| 蓄劲增伤【现有近似】 | 高真气消耗换高威力（现有 power/energyCost 即可表达） | — |

### 2.3 特殊机制

| 机制 | 说明 |
|---|---|
| 阵法【扩展】 | 需我方存活人数 ≥N 才能施放，群体增益或群体伤害（天罡北斗阵、真武七截阵类） |
| 召唤【扩展】 | 召唤助战单位（驭兽、剑阵化形类），挂机战斗中可简化为「额外一段伤害/增益」 |

## 三、数值框架

沿用现有生成公式作为基准，各分卷只做 ±20% 以内的个性微调（并说明理由），避免数值体系失衡：

- **势力武功**：真气消耗 `8 + 阶段 × 4`，冷却 `1800 + 阶段 × 400` ms，威力 `0.8 + 阶段 × 0.35`，学习消耗贡献 `60 × 阶段 + 世界卷数 × 20`。
- **城市通用武功**：真气 `10 + 世界卷数`，冷却 `2500` ms，威力 `0.9 + 世界卷数 × 0.05`，消耗世界货币 `150 + 世界卷数 × 50`。
- **品级**：沿用 `RARITY_BUDGET_BY_WORLD`，各卷表格中给出每门武功的品级，不得改动分布。
- **效果强度换算参考**（以单体直接伤害威力 1.0 为基准）：
  - 群体伤害 ≈ 单体威力的 50%–65%
  - 中毒/流血全额 ≈ 直接伤害的 80%–120%（分摊到持续时间内）
  - 控制类威力减半，补偿控制时长
  - 连击总威力 ≈ 同阶单体 1.1 倍（段数多、易被打断部分闪避）

## 四、武功 ID 与数据结构

- **ID 全部保持不变**（势力武功 `势力id_阶段字母+分支号`、通用武功 `world_XX_common_职业_01`、心法 `势力id_heart_01` / `world_XX_heart_common`），存档、贡献、悬榜均不受影响；只改 `name` 与数值字段。
- 每条武功在分卷中以表格记录：**现有 ID | 新名称 | 出处 | 品级 | 效果设计 | 数值建议 | 引擎落地**。
- 「引擎落地」列填：现有语义（damage/heal/revive/cleanse/guard/dispel + 目标）以及所需的【扩展】机制清单。

## 五、引擎扩展工作量预估

按优先级建议分三期落地：

1. **一期（收益最大、实现简单）**：中毒、破甲/破气、护盾、连击、迟缓。这五个机制即可覆盖 60% 以上的新设计。
2. **二期**：吸血/吸内、点穴/封穴、反伤、闪避/加速、易伤、破绽标记。
3. **三期（结构复杂）**：蓄力、借力、夺益、复制、阵法、召唤、击退、狂暴、自损。

各分卷中标注【扩展】的武功若机制尚未落地，可先用现有语义近似（如中毒近似为低威力直接伤害），待机制上线后再切换。

## 六、心法体系

- 每势力 1 门心法、每世界 1 门通用心法，同样重命名为原著内功名（先天功、易筋经、北冥神功、紫霞神功、龙象般若功……）。
- 心法数值字段（energyRecovery / gaugeRate / cooldownRate / momentumBonus / survivalBonus）维持现有公式，各卷只做名称与文案设计；如需个性微调同样控制在 ±20% 内。
