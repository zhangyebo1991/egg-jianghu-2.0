# 卷七 · 蝴蝶谷

蝴蝶谷是《倚天屠龙记》中「蝶谷医仙」胡青牛的隐居之地，张无忌在此求医学医、初窥九阳门径。本卷以《倚天》为武学主脉：明教的刚拳与绵掌、武当的太极内家、峨眉的灭绝双剑在此交汇，通用心法以九阴真经收束，正应张无忌身兼数派绝学的剧情底色。
