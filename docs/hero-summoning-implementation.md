## 概率和保底

以下均为本作设计数值，不是原版抽卡数据。

| 项目 | 数值 |
| --- | --- |
| 单抽／十次招募 | 100／1000蛋蛋，需预先持有全额 |
| 名侠基础概率 | 1%，同章同档均分 |
| 传奇基础概率 | 0.2%，同章同档均分 |
| 普通结果 | 98.8%，初晶矿石×2／灵风松木×2均分该概率 |
| 侠客保底 | 连续70抽内必得名侠或传奇 |
| 传奇保底 | 连续280抽内必得传奇 |
| 心愿保障 | 选定后连续560抽未获得目标，必得指定传奇 |
| 重复返还 | 名侠10蛋蛋、传奇20蛋蛋，不覆盖原培养 |

- 无软保底、无收益卡概率加成。心愿只提供上限，不提升基础概率。
- 同次触发按心愿、传奇、侠客保底依次优先，只发一个结果。十次招募逐次结算，享受同样保底。
- 任意侠客重置侠客计数；传奇同时重置传奇计数；目标同时重置心愿计数。重复获得也重置相应计数。
- 每章独立保存。切章、退出、继续游戏不清零；切换目标只重置该章心愿计数，重选同一目标不重置。
- 基础日上限700蛋蛋，相当于7抽。心愿最迟80天的口径是每天拿满、全投入同章、不更换目标；其它消费、分池投入、未拿满都会延长日历时间。

## 原版参考与模拟

原版本地证据：[势力招募目录](evidence/original-world/faction-recruitment-catalog.md)。关羽、诸葛亮需声望5与160000贡献，扫地僧需声望5与290000贡献。参考的是长期声望／资源积累门槛；没有把这些价格推断为已经测定的原版天数。

`src/domain/hero-summoning-simulation.test.ts`用实际结算函数模拟13章，每章64个固定种子，共832组。每章从零收集，取得心愿后转向下一位未拥有传奇；每日700蛋蛋均投入本章，计入重复返还，不计解锁章节、养成与其它消费时间。

- 首次任意名侠或传奇平均6.75天。
- 首次传奇平均30.34天，所有样本不超过280抽。
- 每次选定且未获得的传奇均在560抽内出现。
