## 1. 设计定位与核心支柱

### 1.1 一句话定位

> 挂着挂着就变强，但真正让你上头的是"用哪几个侠客、怎么排兵布阵、走什么武学路子"的组合决策。

### 1.2 三大设计支柱

| 支柱 | 说明 | 反面（要避免的） |
|------|------|------------------|
| **收集有意义** | 每个侠客不是数值皮肤，而是解锁新组合可能性的钥匙 | 抽到就是加属性、可被高星完全替代 |
| **组合即深度** | 战力上限由 build 组合决定，而非单纯堆数值 | 唯一最优解 build、无脑堆等级 |
| **挂机有回报** | 离线也在推进，回来有正反馈和新决策点 | 必须盯着屏幕手操、离线归零 |

### 1.3 无氪金下的价值锚点

- **付费墙 → 时间墙 + 决策墙**：卡点靠"资源积累时间"和"组合是否想对"，不靠钱。
- **深度来自 build 多样性**：同一批侠客，不同阵型/羁绊/武学搭配 = 完全不同的战斗表现。
- **续命靠新周目**：转生（重开带增益）+ 新区域内容，替代付费长线运营。

## 2. 核心游戏循环

### 2.1 循环图

```
        ┌─────────────────────────────────────────────┐
        │                                             │
        ▼                                             │
   [挂机产出]  ──►  [资源/经验/物品]  ──►  [养成 & 组合]  │
   历练/闯荡         江湖阅历、内力            配队、排阵、    │
   （tick 驱动）      材料、机缘             习武、结羁绊     │
        ▲                                        │        │
        │                                        ▼        │
   [解锁新内容] ◄──  [挑战关卡/BOSS] ◄──  [战力提升]────────┘
   新侠客/新区域        自动战斗+可视化
   /新武学
```

### 2.2 循环节奏（三层时间尺度）

| 尺度 | 玩家动作 | 频率 |
|------|----------|------|
| **秒级** | 看战斗可视化、飘字、日志 | 挂机时被动观看 |
| **分钟级** | 调阵型、换武学、切挂机地点 | 每次卡点/变强后 |
| **小时~天级** | 收集新侠客、凑齐羁绊、冲新区域、转生 | 长线目标 |

### 2.3 关键：每次"变强"都要制造一个"新决策点"

变强不能只是数字变大，要让玩家产生"我现在能不能换个 build / 解锁的新侠客要不要进队"的思考。这是耐玩性的核心引擎。

## 3. 四层组合系统（核心玩法）

这是整个游戏的深度来源。四层从"角色内部"到"队伍整体"层层放大，每一层都是独立的决策维度，叠加后产生指数级的 build 空间。

```
第 4 层  合击技      ← 特定组合解锁，队伍级质变
第 3 层  羁绊网络    ← 侠客之间的关系加成
第 2 层  阵型站位    ← 位置与阵法
第 1 层  武学相性    ← 单个侠客内部的属性取舍
```

> **MVP 只做第 1 层（简化）+ 第 3 层（门派羁绊）+ 第 4 层（1 个合击技）**，第 2 层阵型留到迭代 2。详见第 5 章。

### 3.1 第 1 层：武学相性（角色内部）

单个侠客要在**内力属性**上做取舍，不同取舍改变其战斗风格。

- **刚柔轴**：刚（高攻击、低闪避）↔ 柔（高闪避、高连击）。角色有天赋倾向，玩家通过习武偏向强化某一端。
- **阴阳/五行**（简化五行：金木水火土）：每个侠客有本命属性，武学也有属性。**同属性武学 = 威力加成；相克属性 = 走火入魔风险**。
- **走火入魔取舍**：强行修习相克或超阶武学 → 短期战力暴涨，但叠加"心魔值"，心魔满则触发负面状态（出手概率降低/自损内力）。高风险高回报的 build 选择。

**决策点**：一个侠客是"稳健纯属性流"还是"搏命走火入魔流"，由玩家的武学分配决定。

### 3.2 第 2 层：阵型 / 站位（队伍布局）

队伍上场 N 人（MVP 建议 3~5 人），摆在格子里，位置决定承伤与增益。

- **站位格子**：简化为前排 / 后排两行（迭代 2 再上 3×3 八卦阵）。前排承伤、后排输出/辅助。
- **阵法激活**：当站位满足特定条件（如"前排 2 人 + 后排 1 医者"）激活阵法，给全队 buff。阵法是"位置的组合"，不消耗额外资源，纯靠摆放。
- **克制关系**：某些阵法针对敌方阵型有加成（攻阵克守阵等），给挂机地点选择增加决策。

**决策点**：同样几个侠客，摆前摆后 + 凑不凑阵法，输出结构完全不同。

#### 迭代 2 已落地规则

- 三人队伍必须同时保留前排与后排，可在“两前一后”和“一前两后”间切换。
- 前排优先承受敌方反击，受到伤害降低 20%，但造成伤害降低 10%。
- 后排在仍有前排存活时不会被敌方选中，造成伤害提高 15%。
- 两前一后称为“磐石阵”，强调承伤稳定；一前两后称为“雁行阵”，强调输出但唯一前排压力更大。
- 挑战交锋期间不可换人或换位；挂机状态调整阵型后立即重新列阵。
- 当前仍不做 3×3 八卦阵与角色职业条件；阵型和武学克制已在迭代 3 的区域敌人中接受验证。

### 3.3 第 3 层：羁绊网络（侠客之间的关系）

侠客不是孤立单位，彼此之间有**有向、带故事**的关系。这是收集系统的灵魂。

| 羁绊类型 | 触发条件 | 效果示例 | 叙事作用 |
|----------|----------|----------|----------|
| **师徒** | 师、徒同时在队 | 徒弟经验加成、继承部分师父武学 | 传承线 |
| **情侣 / 结拜** | 二者同队 | 双方属性互补加成，一方濒死另一方暴走 | 情感线 |
| **门派** | 同门 ≥N 人 | 门派共鸣，解锁门派武学 | 阵营线 |
| **宿敌** | 二者同队 | 内讧减益 / 或"不打不相识"转化为强增益 | 冲突线 |

- **有向性**：师→徒 和 徒→师 效果不同；宿敌是负向但可通过剧情转正。
- **羁绊网络 = 一张关系图**，玩家为了凑羁绊会主动去收集"关系节点"上的侠客，收集因此有了目标感。

**决策点**：为了触发某条强羁绊，玩家可能愿意让一个数值较弱的侠客上场——**羁绊价值 > 裸数值**。

### 3.4 第 4 层：合击技 / 联手武学（队伍级质变）

当队伍中同时存在**特定侠客组合**时，解锁一个专属"合击技"——不是数值加成，而是**新增一个战斗中会自动释放的强力技能**。

- **解锁条件**：由 2~3 名指定侠客同时在场触发（可叠加羁绊/门派条件），例如"降龙十八掌 + 打狗棒法"双人合击。
- **效果形态**：合击技是独立技能，进入自动战斗的技能轮询池，按 CD / 内力触发；表现上有专属特效和战斗日志文案。
- **稀缺性**：合击技组合数量有限且需要收集齐特定侠客，是**长线收集的核心驱动力**（"就差一个人就能凑出这个合击了"）。

**决策点**：为了一个强力合击技，玩家可能重构整支队伍——合击技是"组合决策"的最高层放大器。

### 3.5 四层如何叠加（组合示例）

一支队伍的最终战斗表现 = 四层叠乘的结果：

```
单个侠客走"柔 + 水属性"（第 1 层）
  → 摆在后排、凑成"医者阵"（第 2 层）
    → 与队内师父触发"师徒传承"羁绊（第 3 层）
      → 全队集齐 3 人解锁"梯云纵合击"（第 4 层）
```

同一批侠客，改动任意一层都会产生完全不同的 build。**深度 = 层数相乘，而非数值相加**，这是无氪金前提下耐玩性的数学基础。

## 4. 耐玩性设计

无氪金的长线动力来自**新决策 + 新目标 + 新周目**三条腿，而不是数值付费。

### 4.1 三类长线驱动

| 驱动 | 机制 | 作用 |
|------|------|------|
| **收集驱动** | 侠客图鉴、羁绊图谱、合击技清单未集齐 | "就差一个人"的目标感 |
| **build 驱动** | 关卡/BOSS 有软性克制，逼玩家换组合 | 避免唯一最优解，制造 rebuild 乐趣 |
| **进度驱动** | 新区域、新门派、新武学阶梯解锁 | 明确的前进方向 |

### 4.2 转生 / 新周目（续命核心）

- **转生**：角色达到阶段上限后可"重开"，清空等级但保留**转生点数**，用于永久加成或解锁新起点武学。
- **新周目内容**：每周目解锁更高难度区域 + 专属侠客/羁绊，让"重开"有新东西看，而非纯数值刷。
- **软性天花板**：不设硬性等级墙，用"边际收益递减 + 转生更划算"自然引导玩家进入下一周目。

### 4.3 反枯燥设计

- **离线补算有正反馈**：回来必有结算面板（打了多少、掉了什么、是否卡住），而非静默推进。
- **卡点即提示**：战力打不过时，明确提示"可尝试的方向"（换羁绊/凑阵法/走火入魔），把卡点转化为决策而非劝退。
- **小抽卡快乐**：机缘/秘境产出侠客碎片，短周期给正反馈，但不与付费挂钩。

## 5. MVP 范围与迭代切分

原则：**先跑通"挂机 → 配队 → 变强"闭环 + 最小组合系统**，验证核心乐趣后再叠层。YAGNI 优先。

### 5.1 MVP（迭代 1）必做

| 模块 | 范围 |
|------|------|
| **挂机核心** | 单挂机地点、tick 产出资源/经验、离线补算 + 结算面板 |
| **侠客系统** | 8~12 名侠客，含属性、本命五行、所属门派 |
| **组合系统** | 第 1 层（简化：刚柔 + 五行加成，暂不做走火入魔）+ 第 3 层（门派羁绊）+ 第 4 层（1 个合击技） |
| **自动战斗** | 3 人小队 vs 敌方，技能轮询、可视化 + 战斗日志 |
| **存档** | localStorage 存/读 + 导出/导入 JSON |
| **界面** | Tab 式：挂机 / 侠客 / 队伍 / 战斗，纯 DOM+CSS |

### 5.2 迭代 2（已完成）

- 三人队伍前后排、逐侠客气血、前排优先承伤、磐石阵与雁行阵已落地。
- 挑战期间锁定换人/换位，version 2 存档兼容旧版队伍。

### 5.3 迭代 3（已完成）

| 区域 | 收益倾向 | 普通敌人 / BOSS 特性 | 推荐破局 |
|------|----------|----------------------|----------|
| **青石古道** | 银两、阅历均衡 | 破阵重击：单前排受创加重 | 两前一后的磐石阵 |
| **黑风寨** | 阅历与残页提高 | 黑铁重甲：压制前排攻击 | 一前两后的雁行阵 |
| **寒潭古寺** | 残页专精 | 寒罡护体：压制非火系武学 | 火系沧浪降龙掌 |

- 普通敌人提前展示区域特性，BOSS 将同一规则放大为 build 检查。
- 击败区域 BOSS 才会解锁下一地区；所有地区支持主动选择与独立败敌进度。
- 在线战斗和离线补算使用当前区域收益倍率，结算面板标明历练地点。
- 存档升级为 version 3，并迁移 version 1 的队伍和 version 2 的阵型/破关进度。

### 5.4 迭代 4（已完成）

- 五门武学均获得专属自动招式与独立冷却，不再只是数值倍率和战斗名称。
- 战斗加入灼伤、迟滞、破甲、护体四类状态，支持持续回合、刷新与可视化。
- 沧浪降龙掌负责爆发与灼伤，凝霜十三剑负责连击与迟滞，太极吐纳法负责治疗护体。
- 金刚伏魔棍负责破甲，厚土归元功负责全队护体，形成输出、控制、续航、增伤、防守五种职责。
- 侠客页、藏经阁、战斗卡片与挑战预案均展示招式信息，战斗日志明确记录状态效果。
- 存档升级为 version 4，version 1～3 导入后会重建兼容的新战斗状态。

### 5.5 迭代 5（已完成）

- 五条具名关系覆盖师徒、结义、知音、宿敌、同道，关系故事与战斗效果均在羁绊图谱中展示。
- 羁绊提供减伤、治疗强化、招式加速和攻击强化等差异化被动，不再只有门派人数加攻。
- 合击从单一「山河照影」扩展为四式，包含纯伤害、全队回复、全队护体和破甲四类结果。
- 三人队伍可同时激活多式合击，并在每三个回合到来时按顺序轮换施展。
- 队伍页新增羁绊图谱与联手武学录，区分尚未结识、已收集待编队、当前生效三种状态。
- 存档升级为 version 5，旧版本导入后会重建合击轮换和关系加成所需的战斗状态。

### 5.6 迭代 6（已完成）

- 新增五层「无相秘境」连续探索，每层开始前从两条随机种子决定的岔路中选择一项临时祝福。
- 六类祝福覆盖伤害、减伤、治疗、招式冷却、最大气血和战利品，可在单轮内重复叠加。
- 五名秘境守关敌人复用区域特性，逐层检验阵型、武学、状态、羁绊与合击形成的完整 build。
- 每层胜利立即永久结算战利品；战败或主动离开只清空本轮祝福与路线，不追回已得资源。
- 秘境记录保存累计通关次数与历史最深层数，进行中的路线、祝福和层战斗均可随存档恢复。
- 秘境期间锁定养成、换人、换位、换武学与区域切换，避免在层间绕过本轮 build 约束。
- 存档升级为 version 6，并继续兼容 version 1～5。

### 5.7 后续迭代（YAGNI 明确推迟）

- 3×3 八卦阵与更完整的阵法克制链。
- **走火入魔**完整机制（心魔值、负面状态）。
- **转生 / 新周目**、多周目专属内容。
- 更多羁绊类型（师徒 / 情侣结拜 / 宿敌完整叙事）、多合击技。
- 扩展玩法：门派经营、秘境 Roguelike、爬塔、五行完整克制链。

### 5.8 验收标准

- 玩家能挂机 → 攒资源 → 养侠客 → 配队打过一个此前打不过的关卡。
- 至少存在一次"为凑羁绊/合击技而调整队伍"的真实决策。
- 玩家必须能通过磐石阵、雁行阵和火系武学分别破解三类 BOSS，而非只靠战力碾压。
- 区域首胜解锁、选区收益与离线倍率在存档刷新后保持一致。
- 关掉再打开，离线收益正确结算，存档不丢。
