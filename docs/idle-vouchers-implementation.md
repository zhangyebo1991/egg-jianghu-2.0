# 基础挂机蛋蛋实施记录

日期：2026-09-11。仅实现用户授权的蛋蛋产出、离线补发与显示；卡池、消费、皮肤收回均未执行。

## 已实现规则

- 驻守或闯荡时按真实时间积累，每六分钟十蛋蛋，七小时达到每日 700 上限；战斗倍速不加速蛋蛋。
- 北京时间 00:00 刷新额度，跨日逐段结算；旧日不足六分钟部分结算整数蛋蛋尾款，不足一点余量清零。
- 在线、后台、休眠和退出共用同一结算游标与每日额度。跨多日离线按各日上限处理，中间完整日直接汇总，不重放战斗。
- 退出前仍处于驻守/闯荡，下一次点击继续游戏时补发蛋蛋并立即保存，避免重复领取。只补蛋蛋，不补经验、装备、材料或战斗进度。
- 继续游戏后沿现有流程回到游戏界面，不自动重启战斗；补发时清除旧挂机标记，重新开始驻守/闯荡后继续积累。主动停止先结算再清标记。
- v19 存档增加 idleVouchers，旧档缺省为零余额、未挂机，不追溯未记录的历史。原角色、皮肤、装备等数据保留，保存冲突保护继续有效。
- 进入挂机、切换模式、主动停止及时保存；在线定期保存和退出保存记录进度。云存档校验与序列化保留新增字段，不在服务端计算挂机收益。

## 显示

侧栏显示蛋蛋余额及今日领取数。桌面将鼠标移到蛋蛋上显示悬浮详情，移出后关闭；也可点击旁边的 `?` 固定显示，手机直接点击 `?`。详情包含下一次到账时间、距当日领满的有效时长、每日规则和本次离线结算数，浮在页面上且不挤动侧栏。再次点击 `?`、点击外部或按 Esc 关闭，不增加定时领取弹窗。后续周月卡购买及效果见 [周月卡实施记录](premium-cards-implementation.md)。
