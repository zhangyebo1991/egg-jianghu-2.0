# 蛋蛋江湖 2.0 · UI 素材清单 v1

高保真原型 `docs/UI高保真_v1.html` 引用的全部图片素材。
**生成后请放到仓库根目录 `assets/ui/` 下，文件名严格按下表**（HTML 按 `../assets/ui/<文件名>` 引用，缺图时自动回退到文字印章，不会报错）。

## 统一风格基准（每条 prompt 都会带上）

> 中国水墨风（shui-mo），单色松烟墨 + 微暖宣纸调，干笔飞白质感，留白克制，游戏 UI 用图，构图居中，**画面中不要任何文字、印章、水印**。夜册面板底为深墨近黑（#191611），素材需在其上融合良好。

英文风格锚（生成时可附加）：`Chinese ink wash painting, sumi-e, dry brush strokes, monochrome ink with warm paper undertone, centered composition, dark charcoal-brown ink background (#191611), atmospheric, no text, no watermark, game UI asset`

## 生成后自检

1. 文件全部落在 `assets/ui/`，命名与上表逐字一致（区分大小写）。
2. 用浏览器打开 `docs/UI高保真_v1.html`：战场令牌、行囊格子、侠客册页头像自动换图；未生成的文件保持文字印章不受影响。
3. `bg-battlefield.png` 就位后主界面会自动隐藏内置山峦矢量图、切换为生成底图。
