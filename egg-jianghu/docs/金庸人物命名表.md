# 金庸人物命名表（酒馆 / 势力 / 可招募角色）

> 本表取代 `docs/superpowers/plans/2026-08-03-jianghu-30-world-names.md` 中"不改势力名"的决定，是本任务的金庸化命名单据。
> 范围：已开放的 10 卷（world_01~world_10）。敌人/BOSS/武功体系/世界名均未改动。

## 设计规则

- **每卷 3 势力**，类别可调，六类（剑/刀/拳/暗/医/内家）总数严格各 **5**。
- **势力可招募角色 3 名**，**城市酒馆 3 名**，全部为金庸原著人物。
- 可招募角色**避开本卷已作敌人/BOSS 的角色**（跨卷复用允许并注明）。
- 少数大派按原著横跨多卷，每卷用不同门人：丐帮×3、全真教×2、逍遥派×2、大理段氏×2、灵鹫宫×2、渔樵耕读×2。
- ⚠ 标注"松关联"的取舍：原著在该类别无完美门派，取最贴切者。
