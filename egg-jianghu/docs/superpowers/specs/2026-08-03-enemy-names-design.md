# 蛋蛋江湖 2.0 前 10 大关敌人命名设计（金庸风）

## 背景

江湖世界已改为 30 卷金庸地名（前 10 卷开放）。但每卷内部的小怪/Boss 目前仍是程序化占位名：普通为「第N关敌手」、精英为「第N关精英」、Boss 为「第N关首领」，与大关卡名毫无关联，缺乏武侠辨识度。玩家要求按大关卡名（牛家村、嘉兴、归云庄……）为前 10 大关的小怪与 Boss 配上金庸风、武侠风的名字。

## 目标

- 前 10 大关（world_01~world_10）各自拥有专属的小怪名池与 Boss 名单。
- 每大关 10 小关、每小关一个 Boss，即 10 大关共 **100 个 Boss 名**，全部致敬金庸原著人物。
- 普通/精英小怪用每大关专属的武侠风名池（普通 ≥6 个、精英 ≥3 个）。
- 名字是敌人 ID 的**纯函数**：战斗内生成与悬榜反查走同一数据源，保证一致。
- 未开放卷（world_11+）沿用现有通用占位名，不受影响。
- 存档 schema、战斗数值、掉落规则、势力数据均不变。

## 数据模型

### 新增 `src/content/enemy-names.ts`

```ts
export interface WorldEnemyNames {
  normal: string[]  // ≥6，保证满波次 5 个普通怪不重名
  elite: string[]   // ≥3
  bosses: string[]  // length === 10，下标对应第 1~10 小关
}

export const ENEMY_NAMES_BY_WORLD: Record<string, WorldEnemyNames>
// world_01 ~ world_10 各一份
```

解析函数（纯函数，名字是敌人 ID 的确定性函数）：

| 品级 | 敌人 ID 示例 | 名字取值 |
|------|-------------|---------|
| boss | `world_03_stage_07_boss` | `bosses[stage - 1]` |
| elite | `world_01_stage_04_elite_2` | `elite[(序号-1) % elite.length]` |
| normal | `world_01_stage_01_normal_3` | `normal[(序号-1) % normal.length]` |

- `enemyName(worldId, rank, stage, index)`：战斗内 `createEnemy` 生成名字。
- `enemyDisplayName(enemyId)`：解析 `worldId / stage / rank / 序号` 后走同一套逻辑（正则由 `/ _stage_(\d+)_(normal|elite|boss)(?:_\d+)?$/` 扩展为同时捕获 `world_(\d+)` 前缀与序号）。
- 兜底：`worldId` 不在表内（未开放卷或坏 ID）→ 沿用通用占位名「第N关首领/精英/敌手」；无法解析 → 「未知目标」。

## 代码改动

### `src/combat/waves.ts`

- `enemyName(rank, stage)` 改为 `enemyName(worldId, rank, stage, index)`，委托 `enemy-names.ts`。
- `createEnemy` 生成 `name` 时传入 `worldId` 与 `index + 1`。
- `enemyDisplayName` 改为委托 `enemy-names.ts` 的解析（保持从 `waves.ts` 导出，`main.ts` 导入路径不变）。

### `src/content/validate.ts`（可选）

- 若现有 validate 校验内容数据完整性，可顺带校验每大关 Boss 数 = 10、普通名 ≥ 6、精英名 ≥ 3。

## 测试调整

### `src/combat/waves.test.ts`

- 更新 3 条名字断言为真实名字（如 `world_01_stage_01_normal_1` → 牛家村普通名、`world_10_stage_10_boss` → 无崖子）。
- 新增数据完整性断言：每大关恰好 10 个 Boss；普通名 ≥ 6、精英名 ≥ 3；跨大关 Boss 不重名。
- 保留坏 ID → 「未知目标」断言。

### 其他

- `pages.test.ts` 中 fixture 的 `第1关敌手` 为 mock 字符串，不依赖真实解析，不会破坏；可顺手改为真实名字保持一致性。
- e2e 无敌人名字断言，无需改动。

## 范围说明（非目标）

- 不改敌人 ID 格式、战斗数值、Boss/精英出现规则（波次 10 出 Boss 等）。
- 不改悬榜目标选取逻辑（仍按 enemyId 反查名字显示）。
- 不给 Boss 加门派/称号前缀（如「东邪·黄药师」），保持名字简洁；如需称号风可作为后续扩展。
- 不处理未开放卷（world_11+）的敌人命名。
