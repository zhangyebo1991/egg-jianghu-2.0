# 蛋蛋江湖 2.0 前 10 大关装备命名设计（金庸风）

## 背景

江湖世界已改为 30 卷金庸地名（前 10 卷开放）。但每卷的装备目前仍是程序化占位名：统一为「第N卷兵刃」「第N卷冠巾」……与大关卡名毫无关联，缺乏武侠辨识度。参照已完成的前 10 大关敌人命名改造（`enemy-names.ts`），为前 10 大关的 10 卷 × 7 槽位共 **70 件装备**配上金庸风、当地风的手写名字。

## 目标

- 前 10 大关（world_01~world_10）各自拥有专属装备名，每大关 7 槽位各一件。
- 名字是 (worldId, slot) 的**纯函数**：定义表与展示走同一数据源，保证一致。
- 名字**全局不重名**：跨大关、跨槽位共 70 个名字互不重复，玩家可从名字分辨来源大关。
- 未开放卷（world_11+）沿用现有程序化占位名「第N卷+槽位名」，不受影响。
- 装备 ID、槽位、品质、基础数值、掉落规则、存档 schema、UI 布局均不变。

## 命名方案

### 命名原则

1. **世界观专属**：每大关一个主题，7 槽位围绕主题展开（牛家村=粗朴农家、姑苏=江南雅致……）。
2. **槽位贴合**：兵刃是武器、冠巾是头饰、衣甲是衣着、护腕是腕甲、腰佩是腰带/腰间物、履靴是鞋、信物是凭证/珍藏。
3. **全局不重名**：70 个名字跨大关、跨槽位不得重复（写入校验）。
4. **篇幅 2~5 字**，与敌人名池风格一致；**隐式递进**——低卷粗朴、高卷精奇（柴刀→鎏金长剑→玄铁棋剑），词面自然读出成长感。

**设计要点：**

- **兵刃递进线**：柴刀 → 铁尺 → 铁桨 → 鎏金长剑 → 无量剑 → 雁翎刀 → 金针 → 玉骨折扇 → 虎头刀 → 玄铁棋剑，粗朴到精奇。
- **信物线**：每件都是当地最有辨识度的凭证/珍藏，如聚贤令（英雄帖）、珍珑棋谱（擂鼓山镇山）、参合玉令（姑苏慕容）。
- **逍遥派呼应**：无量山「琅嬛玉简」与擂鼓山「逍遥巾/珍珑棋谱」同源于逍遥派，符合原著设定（琅嬛福地、珍珑棋局均为逍遥派传承）。

## 数据模型

### 新增 `src/content/equipment-names.ts`

```ts
import type { EquipmentSlot } from './equipment'

export type WorldEquipmentNames = Record<EquipmentSlot, string>

export const EQUIPMENT_NAMES_BY_WORLD: Record<string, WorldEquipmentNames> = {
  world_01: { weapon: '柴刀', head: '斗笠', armor: '粗布短衣', wrist: '裹腕麻布', waist: '系腰草绳', boots: '芒鞋', token: '半枚玉佩' },
  // …world_02 ~ world_10 同理
}

// 纯函数：名字是 (worldId, slot) 的确定性函数；缺表返回 undefined 由调用方兜底
export const equipmentName = (worldId: string, slot: EquipmentSlot): string | undefined =>
  EQUIPMENT_NAMES_BY_WORLD[worldId]?.[slot]
```

- `import type` 仅为类型，运行时被擦除，与 `equipment.ts` 无运行时循环依赖。
- 兜底：`worldId` 不在表内（未开放卷或坏 ID）→ 返回 `undefined`，由生成器降级为「第N卷+槽位名」。

### `src/content/equipment.ts`（3 行改动）

```ts
import { equipmentName } from './equipment-names'
// 生成器内：
name: equipmentName(worldId, slot) ?? `第${worldIndex}卷${slotNames[slot]}`,
```

- `main.ts` 经 `equipmentDefinitionById().name` 展示，自动生效、零改动。

### `src/content/validate.ts`（追加）

- 已开放 10 卷：`EQUIPMENT_NAMES_BY_WORLD[world.id]` 存在，且 7 槽位名均非空。
- 全局唯一：遍历全部 70 名，重复即报错（防跨大关/跨槽位撞名）。

## 测试调整

### 新增 `src/content/equipment-names.test.ts`（镜像 enemy-names.test.ts）

- 已开放 10 卷每卷 7 槽位齐全、名字非空。
- 跨大关、跨槽位 70 名全局不重名。
- 取值正确：`equipmentName('world_01', 'weapon')` → 柴刀、`equipmentName('world_10', 'token')` → 珍珑棋谱。
- 兜底：缺表世界返回 `undefined`（由生成器降级为程序化占位名）。

### 其他

- `pages.test.ts` 中 fixture 的 `青石剑` 为 mock 字符串，不依赖真实内容表，不会破坏。
- e2e 无装备名断言，无需改动。

## 范围说明（非目标）

- 不改装备 ID、槽位、品质、基础数值、掉落规则、存档 schema。
- 不改 UI 布局与 `main.ts`（品质徽章仍独立显示）。
- 不处理未开放卷（world_11+）装备命名，沿用「第N卷」占位兜底。
- 不做品质递进命名（凡品~绝品同名，仅徽章区分）。
